# 总编裁决与出版装配

本文件是 `formal_comprehensive` 面向读者表达的唯一事实来源，并拥有总编裁决。它定义总编如何把已接受章节组织成一份由价值路径逐层推出部署方案的项目报告；`report-contract.md` 继续拥有状态、版本、接受和装配契约，`quality-gates.md` 继续拥有分析质量判断。

## 总编职责

总编在全稿分析审校通过后读取已接受章节、`decision-logic-map`、`decision_inventory` 和证据摘要。总编维护项目推理主线、章节职责和读者节奏，不把专业工作包、指标类型或研究方法当作报告目录。

总编的综合内容只引用接受章节：执行摘要先展示价值路径的受益者、当前状态、期望改变和一期部署样板，再说明这个样板怎样生成可见产出、近期结果与可复制机制；随后明确项目角色、定位和资源组合。空间、许可、权益、承载和退出条件只在解释样板怎样运行、怎样改变资源优先级与何时调整时出现。过渡说明一个判断怎样推进下一个选择；综合结论收束已成立的资源投入、学习记录和复制顺序。专业判断、证据解释和章节正文由章节作者保持所有权。

## 出版核对

- 主文必须让读者顺序读出：目标结果与核心矛盾 → 项目角色与关键能力 → 定位与价值承诺 → 部署样板工作流 → 空间运行边界 → 一期部署与学习闭环 → 复制与扩展决策门。
- 每个读者可见章节都使用“问题 → 价值路径与机制 → 证据与判断 → 下游影响”推进：先说明为谁创造什么改变、通过什么部署样板实现，再以证据与反证校正实现方式；章节标题以项目对象、当前选择或下一步行动命名。
- 为每项 `decision_inventory` 决策登记唯一完整论证的所有者章节，并登记它消费的上游判断和交给下游的限制。任一环节若不能改变后续定位、产品、空间、运营或分期，就不进入主文。
- R2 的项目角色资格必须有正文位置。资格不足时，报告必须完整呈现伴生承接区、线路节点、社区服务设施或产业服务节点等降级路径，不得为保留宏大定位跳过结论。
- R3 至 R5 必须形成资源或能力到部署样板的连续转译：价值承诺 → 使用者触发 → 服务或参与 → 空间/数字界面 → 运营者 → 真实记录。空间结构是工作流的承接条件。
- R6 的一期至少说明目标使用者、核心体验或服务、空间与服务承接、价值交换或公共作用、运营主体、资源投入优先级、条件性启动预算包、即时产出、近期结果、关键假设与复制/调整条件。需要上会的首期将服务界面、内容单元和空间单元捆绑为可见样板，并给出可检验的使用、内容、协同和冲突控制记录。
- 价值路径须明确区分一期介入窗口与结果/影响观察窗口，并记录各主要受益者的时间节奏。远期影响以条件性路径呈现，近期记录是一期决策的直接依据。
- 为共同事实、材料冲突、代理边界和实施条件登记首次完整解释的位置；关联章节只呈现这些事实对自身选择或动作的后果。
- 证据来源、年份、范围、口径、反例和许可边界在改变选择处出现，其余集中到证据审计。不得用共同限制、风险清单或研究过程替代项目故事和方案。

## 分型表达

文旅或遗产项目可沿“到达、体验、停留、消费、夜间或过夜、复访”组织行为闭环，但夜游、住宿和商业支付只在相应需求、空间、安全和运营条件成立时出现。社区或公共服务项目以真实服务对象、居民权益、公共任务和组织履约组织闭环；产业或园区项目以企业或员工需求、采购或服务关系、生产空间和经营机制组织闭环。任何不适用的链条都必须说明原因，不得机械套用文旅表达。

## 定向返写

总编为每项出版核对登记“就绪”或“定向返写”。定向返写单路由到拥有相应决策的原章节作者；作者沿用原证据包生成新版本，通过双审校后回到出版装配。

返写单说明保留的判断、唯一正文归属、断裂的上游或下游关系、作者需要补足的出版核对项，以及重新审校的章节范围。

## 完成条件

总编裁决完成时，每项重要决策有唯一完整正文归属，六段推导链没有跳步，项目角色资格和降级路径已闭合，空间结构可追溯到产品或服务逻辑，一期构成最小完整闭环，每个章节承担不同的读者职责，总编综合只引用接受章节。实施条件没有吞没主体分析；所有返写章节均已通过双审校，出版装配使用这些接受版本的完整文本。

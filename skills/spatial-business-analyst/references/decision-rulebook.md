# 空间商业方案推导规则手册

本手册拥有正式分析的前台推理结构。它不把资源、市场、客群、空间和运营当作平行章节，而把项目事实、直接研究证据和已保存空间指标串成一条从目标结果到部署样板、学习闭环和复制决策的价值路径。状态恢复、章节审校和报告装配仍由各自契约拥有。

## 逻辑链节点

每个进入 `decision-logic-map` 的节点都必须消费前一节点的判断，并把当前结论交给下一节点。先完成唯一的 `value_path`，再用节点判断如何实现或校正其中的目标结果、部署样板与复制条件。项目不适用某节点时，写明项目特征和不适用理由；社区、产业和公共服务项目以真实服务对象、履约与协同任务组织价值路径。

```yaml
id: R1
decision_question: 本节点必须回答的项目问题
when:
  - 上游判断、已观察到的事实、比较关系或约束
judgment: 当前判断
action: 因此改变的定位、空间、产品、运营或分期动作
alternatives: []
counterexample: 条件不成立时应采取的替代路径
evidence_refs: []
metric_refs: []
limitations: []
validation: 会确认、缩减或推翻当前判断的后续证据
status: supported | conditional | excluded
```

`when` 首项写明上游判断；`action` 末尾写明“下一步必须回答什么”。规则不是工作步骤、章节标题或抽象倡议。部署范围发生变化时，在 `action` 说明一期样板或资源优先级怎样调整，并在 `validation` 说明何时复制、缩减或停止。每个 `metric_refs` 项记录 `result_id`、`tool_id`、观察、比较基准、对规则的作用和不可推断边界；没有改变行动的指标不进入节点。

## 六段方案推导链

### R1 目标结果与核心矛盾

从受益者当前实际发生的使用、服务或治理状态出发，判断一期希望带来的可观察改变。将进入机制不足、已有使用未转化、公共服务缺口、产业服务缺口和权益/生态/生产冲突视为改变目标的条件，而非项目叙事本身。文旅项目可比较到访、停留、消费、过夜和服务承接；社区项目比较真实服务对象和权益；产业项目比较企业、员工、采购和生产服务缺口。已有稳定到访但停留或消费承接不足时，目标转为延长体验和补足承接。空间代理只能限定条件，不能直接证明客流、支付或经营需求。

### R2 项目角色与关键能力

以 R1 的目标结果判断项目应承担什么角色，并明确它凭什么能力兑现价值承诺。文旅或遗产项目只有同时具备核心吸引物、可持续体验、可达与服务承接、空间腹地和运营组织能力，才可比较独立目的地或综合承接区；其他条件组合可形成伴生承接区、线路节点、专题参观或社区文化场所等适配角色。社区和产业项目分别检验服务需求、权利边界、组织履约或采购机制。角色选择必须成为一期部署样板的承接能力。

### R3 定位与价值承诺

仅在 R2 允许的角色范围内比较定位。多个资源由同一历史过程、生产机制、生态关系或日常生活机制连接时，以该共同机制形成主叙事；资源名称并列不能构成定位。定位必须用一句可检验的价值承诺连接目标使用者、独特能力与期望改变。红色记忆、县域文脉或非遗若有可核验的真实对象、档案或空间关联，可作为事实性空间身份（如历史年表、对象说明或主路径信息）嵌入；其服务方式由需求、授权与运营承接共同决定。不能同时连接场地、使用者和全年运营的主题保留为专题内容。

### R4 部署样板工作流

把 R3 定位转成一期最小的 `使用者 -> 触发 -> 服务/参与 -> 空间或数字界面 -> 运营者 -> 真实记录` 部署样板。它必须解决一个实际到达、体验、休息、消费、公共服务或生产服务断点，并说明即时产出和近期结果。文旅项目可使用从到达至复访的行为链；社区和产业项目以实际服务或生产流程组织样板。产品、业态与公共服务由该工作流推出。

### R5 空间运行边界

以 R4 的部署样板配置空间，说明使用者流线、服务或生产流线、运营者动作和冲突缓冲如何让工作流真正发生。保护、生态、安全、权属、居民或生产使用、可达和现有运营条件定义样板的运行边界与资源优先级；高强度消费、后勤或建设功能进入经承载与合规核验的低敏感空间。运行边界改变样板时，回到 R4 调整工作流和记录方式。

### R6 一期部署与学习闭环

一期部署把 R4 的样板放入真实运行：明确目标使用者、核心体验或服务、空间与服务承接、价值交换或公共作用、运营主体、资源投入优先级、启动预算包和记录机制。对需要一次性决策的更新项目，首期将服务界面、至少一个可讲述或可使用的内容单元、以及一个可运营的空间单元捆绑为同一验证包。记录同时覆盖即时产出、近期结果、关键假设与不同受益者的时间节奏，并以此作出复制、扩大、调整或停止决定。

启动预算包按公开可得的成本基准形成低位、基准和高位区间，逐项列出范围、单位、数量、来源、适用城市/年份、税费或管理费口径、不可预见费和未计入项。优先使用同城或同省近三年的中标公告/采购文件、公开招聘薪酬、供应商公开报价或平台明码标价；来源只能支持相近工作内容的，须降级为代理推断。它是上会用的条件性概算，不得写成项目已获报价、批准预算或最终合同金额。证据不足时仍给出可复算的参数化区间和询价校准门，而不是只写“单价未知”。

证据不足时仍给出条件性一期组合，并标明扩大、缩减或停止的条件；高资本、难逆转内容在市场、许可、承载、支付、运营或成本条件满足后进入后续阶段。没有形成上述闭环的内容只能作为验证动作、远期储备或退出项。

## 指标绑定

指标首先服从当前规则节点及其下一步问题，再服从目录。优先复用已保存 result ID；缺口指标仅在其结果可能改变当前行动时执行。

| 决策节点 | 优先指标组合 | 能改变的动作 |
| --- | --- | --- |
| R1、R2 | 市场研究、项目原件、`poi.supply_structure`、可达性与路网 | 首要目标、项目角色或降级路径 |
| R3、R4 | 资源调研、市场客群、`people-scenarios` | 定位比较、目标使用者、产品任务 |
| R4、R5 | `regional-direction`、POI、路网、承载与权利资料 | 场景任务、踏勘顺序、公共界面和功能强度 |
| R5、R6 | 夜光方向/梯度/时序、POI、路网、运营资料 | 时段开放、首开范围、资源释放和验证重点 |

`metric-selection.md` 与 `spatial-inference-rules.md` 拥有指标组合、方法口径和不可推断边界；本手册不复制其技术细节。

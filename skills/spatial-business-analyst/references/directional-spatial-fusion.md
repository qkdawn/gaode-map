# 共同空间单元与多指标融合分析

## 为什么必须做方位和空间单元分析

POI、人口、夜光和路网都带有空间位置。只报告“区域有多少家店、平均人口多少、夜光多少”会丢失最重要的项目判断：这些条件究竟出现在项目的哪一侧、离项目多远、是否沿着可到达的道路出现、彼此是否支持或冲突。

因此，只要输入数据包含点、线、面或栅格几何，主 Agent 必须把“在哪里”作为必答问题，而不是把空间位置留给读者自行猜测。

## 共同空间比较单元

跨来源解释前，先选择一个共同空间单元：

- 候选点比较：为每个候选点使用完全相同的等时圈或缓冲参数；
- 单一区域分析：使用同分辨率、同边界的项目内网格或方向分区；
- 项目内部单元：使用材料中实际出现的地块、组团、建筑、开放空间、连接或其他空间对象，但必须说明它与分析网格的关系。

POI、人口、夜光和路网只有在同一空间单元上对齐后，才可以写“同时较高”“供给与可达性冲突”等融合判断。不同年份、不同范围或不同网格的结果不能静默拼接；如果只能做方向线索，要在报告中说明口径。

## 观察总体契约

共同网格结果必须同时记录输入、成功归属和未归属记录数：

```yaml
observation_universe:
input_record_count:
assigned_record_count:
unassigned_record_count:
spatial_unit:
assignment_rule:
```

同一数据源在不同结果中出现不同记录数时，先解释网格、范围和归属规则，再决定是否可比较。H3 结果只能支持其自身空间统计；POI、人口、夜光和路网的联合 finding 只使用共同网格。单源方向结果与共同网格方向结果冲突时，不静默择优，分别说明口径并以共同网格支持跨源判断。

## DirectionalEvidenceMatrix

需要跨源解释的任务至少交付一个 `DirectionalEvidenceMatrix`。推荐结构：

```yaml
spatial_unit:
  type: shared_grid
  description: 同一分辨率、同一范围的共同栅格
  center: [经度, 纬度]
  direction_method: 以栅格中心点相对项目中心划分八方位
  distance_bands: [0-500m, 500-1000m, 1000-1600m]
rows:
  - sector: 东北
    distance_band: 0-1000m
    metrics:
      poi_density: 真实数值和单位
      population_density: 真实数值和单位
      nightlight_mean: 真实数值和单位
      road_coverage_ratio: 真实比例
      road_density_covered_mean: 有路网单元的真实值
      road_integration_covered_mean: 有路网单元的真实值
    comparison_baseline: 与全部共同单元平均值或同距离带其他方向比较
    supporting_evidence: 哪些指标共同支持同一个空间判断
    contradictory_evidence: 哪些指标不一致，不能合并成单一结论
    proxy_boundary: 这些指标不能证明什么
    decision_impact: 会改变哪个踏勘、内容、时段或空间动作
    field_verification_condition: 现场如何确认、继续或停止
```

## 指标组合的解释顺序

1. 先说方向和距离：例如“项目东北侧 0—1,000 米”；
2. 再说 POI 的密度和类别结构：它描述现有功能供给，不是客流；
3. 加入人口：判断周边日常使用基础，但不把人口直接当成项目客群；
4. 加入路网：区分路网覆盖、路网密度、整合度和连通性，不能把无覆盖单元当成低连通；
5. 加入夜光：描述夜间建成环境亮度，只用于安排核验时段；
6. 明确支持、冲突和缺失；
7. 最后落到一个可验证的项目动作。

不允许把多项指标未经说明地加权成“机会分数”“商业指数”或 ROI。多指标冲突本身就是需要现场核验的结果。

## 普通读者表达模板

```text
项目的【方向/距离】出现了【POI类别与密度】；同一批网格的人口【高/低】，路网【覆盖与连接情况】，夜光【高/低】。
这说明【空间条件判断】，但不说明【不能由代理推出的经营结论】。
因此首期建议【具体动作】，现场需要核对【人行/时段/居民影响/安全】；若【通过条件】则继续，否则【调整或停止】。
```

## 缺失与冲突

- 几何可用但没有方向或距离比较：退回章节作者；
- 跨源结果没有共同空间单元：退回，不能写融合 finding；
- 路网 `covered=false`：写“该单元没有可用路网覆盖”，不写“连通性低”；
- 指标值互相冲突：同时呈现支持和冲突，不能只保留有利一侧；
- 只有总量没有可定位单元：降级为背景，不得用于分区或时段结论。

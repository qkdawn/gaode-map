# Spatial Unit Planning

Read the snapshot, data quality, and confirmed unit list before planning. Establish the project-level positioning, program mix, circulation logic, public value, operating principles, and phasing before making unit recommendations.

Process every eligible unit. Each record must include present conditions, target role, candidate functions, preferred scheme, excluded directions, target users, operating requirements, timing, risks, evidence references, and verification actions.

Never silently omit a unit. Assign each confirmed unit one status: `planned`, `excluded`, or `blocked`. For `blocked`, state the missing condition, responsible party, and validation action. Reconcile the final count against the complete unit list.

Perform a portfolio check across units for duplicate functions, missing support functions, movement connections, public-space continuity, day/night use, and implementation dependencies. Keep conclusions conditional when evidence is incomplete.

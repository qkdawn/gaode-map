# 用共治和履约记录替代先验商业模型

运营首期应由“共治+协同+记录”构成，而不是先设招商和营收目标。项目材料明确持续居住与不整体腾退，且文物公布不等于可商业化使用；因此，运营主体至少应同时具备现场管理、居民沟通、内容解释和活动排期能力。若这些能力无法由单一主体承担，应采用管理方负责保护/场地，社区代表参与时段与扰动规则，外部公共文化机构按项目合作提供内容的分工，而非承诺固定合作。

活动分三类。第一类为预约制旧址讲述和记忆征集，主要检验叙事是否能被理解；第二类为低噪院落公共文化活动，主要检验居民接受度、时段和管理成本；第三类为与近端机构的限定时段协同，主要检验是否存在真实的组织化使用。三类都不应在缺乏许可时进入礼堂，也不应默认收费。

价值交换采用公共服务履约优先：参与记录、服务完成、复访、居民冲突、管理工时和场地维护成本是首期核心数据。若未来存在机构采购、项目资助或被验证的付费活动，再分别核算；没有这些证据之前，不提出门票、商铺租金、餐饮坪效或ROI。周边358餐饮与68零售POI只说明日常配套快照存在，不能证明本项目适合开设同类业态。

运营红线包括：不将文化站、老干部大学或文物考古研究所表述为已合作方；不把遗产访客当保底客流；不让外来活动侵占居民出行和安静时段；不在许可未闭合时以夜间活动或商业活动测试容量。若连续试点的冲突率上升、管理成本不可承受、机构协同中断或开放许可受限，则缩减频率、转预约制或暂停，而非以营销补量。

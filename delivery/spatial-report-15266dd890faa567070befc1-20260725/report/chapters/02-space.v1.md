# 把约120米主线做成受控的使用序列

空间策略不是据路网模型宣称“高人流”，而是把材料中从县政府门口到党校楼约120米的主线，转为可踏勘、可管理、可停止的使用序列：入口认知、旧址解释、礼堂前或院落参与、回到非居住优先的离场路径。礼堂是核心节点候选，但不是默认的大型活动场；它的开放、容量和后勤需由保护、消防和管理条件决定。

居民组团必须被视为使用边界而不是游客资源。材料提出三处住宅组团高入住且不整体腾退，这意味着主线和活动应优先在合法可开放的建筑、院落及边缘公共空间组织，避免穿越居民出入、晾晒、休息和安全空间。住户数102与120的冲突也说明在完成产权和常住口径核验前，任何“社区人口规模”或容量测算都不成立。

华夏路第二入口只应作为验证项目。路网结果可用于发现高整合/选择廊道与断点，却不等于真实步行进入；更不能把模型可达写成导流。第二入口需在主入口、拟入口和礼堂前进行工作日与周末分时计数，并同步核验产权、围墙、无障碍、消防、物业管理和居民意见。若其中任一条件不能闭合，首期只保留主入口，不以导视或营销强行弥补。

空间单元的当前决定如下：办公楼、行政楼和礼堂均为**blocked**，直到保护范围、修缮、消防、无障碍、产权和管理许可明确；主线为**planned**的低冲突导览/解释路径，但不代表已建成；居民组团为**excluded**于外来活动承载；华夏路第二入口为**blocked**。支持功能不能遗漏：预约与登记点、卫生间、临时休息、无障碍通行、应急疏散、设备和后勤均需在开放前确认。

首期成功并不是走完全线，而是验证“可清楚进入、可理解、可短停、可不扰民、可安全退出”。若礼堂无法开放，解释任务应外移至许可的前场或数字/纸本辅助，不能用临时沉浸布景掩盖空间不可用。

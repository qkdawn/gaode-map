# 策划推演的行业规则

本页提取《文本顶层逻辑梳理》与《文本顶层逻辑梳理2》中反复出现、会改变项目决策的行业规则。它们不是可以直接套用的结论，也不是文旅项目的标准业态清单；每条规则都必须由本项目证据和比较对象验证。

## 1. 先判断项目在区域价值链中的位置

区域市场总量不是项目成立的理由。必须分开判断：

- 区域是否有稳定到达的人群；
- 他们的停留时间、人均消费和过夜转化是否足够；
- 项目是在制造到访理由，承接既有到访，延长停留，还是提高消费/复访；
- 项目能否与中心城区、主景区、交通节点或周边社区形成互补，而非重复供给。

因此，“有游客”不能直接推出“应建目的地”。当区域到访量大但停留短、消费弱时，项目可以承担的是延长停留、增加消费场景或成为线路节点；当客源、交通或运营能力不足时，项目只能先承担社区服务、预约内容或小规模承接功能。报告必须明确项目是哪一类角色，不能把全部价值链都写成一期任务。

## 2. 用目的地能力而非资源数量判断项目级别

PDF 将目的地能力拆成可比较的组合，而非单看遗产级别或 POI 数：

```text
D = f(A, S, T, C, E, O)
A: 核心吸引物强度
S: 空间承载能力
T: 交通可达性
C: 消费与服务配套
E: 可体验内容
O: 运营组织能力
```

使用规则：

- 核心吸引物可带来首次到访，但不能替代交通、停留和运营；
- 空间承载不仅是面积，还包括保护等级、居住/生产边界、流线、安全和后勤；
- 可达性回答“能否到”，不回答“会不会付费”；
- 服务配套和体验内容共同决定能否把短暂停留转成可持续使用；
- 运营能力是项目级别的硬条件，不得在最后一章才补写。

如其中任一能力缺失，应把项目角色降级为节点、承接区、预约制内容或公共服务，而不是以宣传词补足能力缺口。

## 3. 市场分析必须拆开“体量、结构、流向、时间和动机”

市场体量至少拆成游客/使用量、收入、人均消费、客源地和交通方式。它们分别回答不同问题：

| 变量 | 可以支持的判断 | 不能支持的判断 |
| --- | --- | --- |
| 到访量或周边人口 | 潜在使用背景、市场规模比较 | 项目客流、支付或营收 |
| 收入与人均消费 | 区域消费层级、产品价格带假设 | 单个项目的收入预测 |
| 客源地与交通方式 | 服务半径、到达摩擦、渠道设计 | 到访意愿 |
| 停留时长与行程结构 | 半日、全天、过夜或多日产品的上限 | 项目独占的时间份额 |
| 节假日、季节和昼夜分布 | 开放时段、排期和淡旺季压力 | 常态化需求 |

空间数据的正确位置是补足“流向、可达、时段背景和供给分布”。报告必须把 POI、路网、人口、夜光的结论落入上述某一变量；若不能改变产品时长、入口、客群优先级或空间排期，就不应写入主文。

## 4. 供给比较要回答项目占据哪一个价值环节

同类项目不能只比较“有没有博物馆、古镇、民宿或非遗”。至少从以下维度比较：

- 首次吸引：为什么第一次来；
- 停留理由：为什么从路过变成半日或全天；
- 消费承接：在哪里、为何消费；
- 过夜转化：什么条件让行程从一日延至一至三日；
- 复访/更新：什么内容让用户再次回来；
- 运营门槛：组织、许可、招商、内容供给和现场协调由谁承担。

反例的用法是识别某一价值环节需要的前提。例如大体量景区能做夜游，不表示一个共居更新项目也能做；它反而说明夜间活动需要容量、交通、邻避处理、内容供给和运营班组等完整条件。

## 5. 主题来自共同机制，不来自资源相加

PDF 中最重要的主题提炼规则是：当场地拥有多个资源时，不能把“红色、遗产、非遗、乡村、自然”等并列为定位；必须寻找它们共同参与的**历史功能、生产机制、社会组织或地方生活过程**。

可用的推导格式：

```text
资源群 -> 共同历史/生产/社会机制 -> 主题 -> 叙事 -> 场景 -> 活动 -> 产品
```

资源进入主题的门槛是同时满足：真实出处、能被使用者理解、能落实到至少一个空间/服务单元、并能由组织持续更新。无法满足者可以作为事实性身份标签、年表或档案注释存在，但不得被包装为主打收费体验。

这里的“叙事”用于组织资源意义、使用者理解与体验逻辑，不是产品本身；只有落实到具体场景和参与活动后，才形成可被使用、履约或交易的产品。

## 6. 定位是一个受约束的命题，不是一句口号

第 7 步的定位至少同时回答：项目级别、区域角色、核心客群、主题、空间范围、主产品时长和目标结果。它必须与以下条件一致：

- 土地、保护和居住/生产边界允许什么；
- 区域市场和客源方式支撑半日、全天、过夜还是多日；
- 周边供给的空白在哪里；
- 四季、昼夜和淡旺季能否形成稳定产品节奏；
- 运营组织和资金规模能否承接。

如果定位不能推出“谁在何处使用什么、由谁提供、为谁产生何种价值”，它仍是宣传语，不能进入设计、招商或预算。

## 7. 产品与业态必须构成六类价值链，而非平行清单

PDF 将业态理解为相互衔接的功能，而非餐饮、民宿、展览的堆叠。项目按实际需要选择其中一部分，并明确每类的责任：

| 业态功能 | 解决的问题 | 常见验证指标 |
| --- | --- | --- |
| 引流 | 制造首次到访或被发现的理由 | 来源渠道、预约/咨询、首次到访 |
| 停留 | 让短时到访有足够内容和节奏 | 停留时长、完成率、活动参与 |
| 消费 | 为内容、服务或本地产品建立价值交换 | 真实支付、客单结构、复购 |
| 过夜 | 将一日使用转为一至三日行程 | 住宿转化、夜间使用、次日留存 |
| 产业 | 把项目连接到本地生产、品牌或供应链 | 本地采购、产品协作、就业/订单 |
| 社区 | 形成共识、参与和长期内容更新 | 参与来源、事项闭合、冲突/投诉 |

任何一期不必拥有全部六类，但必须说明自己服务哪几环、哪些环由周边或二期承接。共居项目的一期通常先建立社区、引流和有限停留，不应虚构消费或过夜转化。

## 8. 空间配置必须由产品反推，并服从承载等级

空间不是先画分区再填业态。正确顺序是：

```text
产品功能 -> 所需场景/后勤 -> 使用者流线 -> 容量与保护边界 -> 功能布局
```

保护核心、老建筑、居住/生产空间和新建/可改造空间的承载强度不同。高敏感空间承担展示、导览、安静体验等低冲击功能；服务、消费、集散和可能高频使用的功能优先放在可承受的外围或新建空间。该规则不是“不能做”，而是用空间分层把内容强度、投入与冲突控制变成可设计的选择。

## 9. 运营先于收益，收益必须对应履约能力

业态进入方案前，必须能答出：谁提供内容、谁排期、谁接待、谁维护、谁处理投诉/授权、谁承担成本、收入归谁或公共任务如何验收。政府、学校、研究机构、服务商、产权方、居民和志愿者的协作不是案例装饰，而是持续内容和现场运行的资源投入。

收入逻辑可包含门票、体验、场地、住宿、餐饮、产品、品牌合作或公共服务采购，但每一项都要以真实价格、容量、许可、渠道和组织能力为前提。尚无支付证据时，写为“待验证的价值交换”，不能填入现金流。

## 10. 财务和分期是同一件事

第 11、12 步的先后关系不可倒置：先用建设/运营清单、公开市场价格、使用量情景和周期校验项目，再把可逆、依赖关系少、最能验证核心假设的单元放进一期。

一期的选择原则：

1. 同时交付可见界面、真实内容、可运行空间与责任主体；
2. 优先建设能降低下一阶段不确定性的单元，而不是最容易展示的装饰；
3. 用低位、基准、高位价格与明确未计入项表达成本；
4. 设置扩大、调整、收缩和停止门，门槛必须记录得到；
5. 把大体量修缮、复杂审批、腾退或重资产招商留给证据足够后的阶段。

这使分期不是“把建设切三段”，而是“在资源成熟度、市场验证、建设周期和资金压力之间安排不可逆承诺”。

# 从空间证据到甲方决策的完整推演

本链路按《文本顶层逻辑梳理2》中的项目策划总表收敛。它不是“分析章节目录”，而是一条必须连续消费上游结论的因果链：**任务与约束 -> 角色 -> 市场 -> 供给 -> 客源行为 -> 资源主题 -> 定位目标 -> 产品业态 -> 空间承载 -> 运营收益 -> 客流投资财务 -> 分期修正**。

每一段都必须写出五个组成部分：

```text
本段要替决策者做什么判断？
哪些项目事实、空间数据、市场资料或同类案例可用于比较？
这些证据通过什么机制支持、削弱或区分候选路径？
当前选择是什么，它给谁创造什么可见价值？
该选择给下一段留下哪些对象、规模、边界或能力条件？
```

## 十二步原始推理链

| 步骤 | 决策问题 | 必须完成的推导 | 对下一步的交付 |
| --- | --- | --- | --- |
| 1. 政策任务与场地约束 | 项目必须承担什么公共任务？场地保护、权属、居住、生态、建设条件怎样改变可选方案？ | 把政策任务、场地资源和不可忽略的约束同时转成机会窗口；不能只列限制，也不能用愿景跳过约束。 | 项目可承担的任务边界、可使用资源与待核准事项。 |
| 2. 项目类型与区域角色 | 它在区域中应是目的地、承接区、线路节点、社区服务节点还是产业服务节点？ | 比较区域中心、交通节点、周边景区和同类项目的分工，确定项目靠什么与周边互补。 | 项目级别、主次客群和角色能力门槛。 |
| 3. 市场体量与客源空间动向 | 市场的规模、结构、进入方式和空间流向是什么？ | 将游客量、收入、人均消费、客源地、交通方式、停留时间等资料拆开比较；无真实交易数据时，只能提出待校准的候选客群。 | 有可能到达的客群、到达路径和不能直接承诺的经营变量。 |
| 4. 竞争供给与市场定位 | 同类供给已解决什么，尚未解决什么？ | 按核心吸引物、历史观光、首次吸引、消费承接、住宿转化等维度做同尺度供给比较，找出可被项目承担的增量价值。 | 一个可防御的市场缺口，而非“资源稀缺”的空泛结论。 |
| 5. 客源半径、时间预算与消费动机 | 谁会在何时、以什么动机、投入多少时间使用项目？ | 按本地居民、周边客源、外来游客等分层，结合车程、日程、季节、节假日和场景，判断半日、全天、过夜或多日产品的合理性。 | 优先客群、行为断点、产品时长和消费/公共履约边界。 |
| 6. 资源筛选与主题提炼 | 哪些资源能够共同说明同一个地方机制？ | 从自然、农业、遗产、日常生活和产业资源中筛选可共同解释的历史、生产、社会或生态过程；资源不能平铺成标签。 | 一个可讲述、可运营、可持续更新的主题机制。 |
| 7. 项目定位与目标 | 前六步共同推出的项目，到底向谁承诺什么改变？ | 定位必须同时说明项目级别、区域角色、主要客群、主题、空间结构和可衡量目标；将至少两个候选定位放在同一前提下比较。 | 一句话定位、目标体系和产品/空间的设计命题。 |
| 8. 产品体系与业态组合 | 用什么引流、停留、消费、住宿、产业或社区任务完成承诺？ | 将资源翻译为主题、叙事、场景、活动和产品，并明确各业态解决的客群问题、价值交换与收益/履约方式。 | 可运行的产品组合和每个单元的目标用户、频次与承接条件。 |
| 9. 空间承载与功能布局 | 人、车、服务、后勤、居民/生产者如何在空间内共同运行？ | 由产品反推入口、集散、展示、活动、住宿、服务、后勤与边界；保护等级、容量、流线和安全条件决定产品强度。 | 功能分区、流线、优先改造空间和不可突破的运行边界。 |
| 10. 运营组织与收益结构 | 谁来交付、维护、排期和协同？公共任务与商业收益怎样各自闭环？ | 将业态映射为运营主体、协作对象、工作流、成本责任和收入/履约来源，避免用招商或单场活动替代组织能力。 | 最小组织、协同机制、收入/履约结构和能力缺口。 |
| 11. 客流、投资和财务校验 | 需要多少使用量、投入和现金/公共资金，项目才具备可行性？ | 将客流或使用量预测、投资构成、建设周期、运营成本和价格参照放入同一情景模型；空间代理数据不能充当客流或 ROI。 | 低位、基准、高位情景，关键假设和需要询价/实测的变量。 |
| 11a. 产品分期校核 | 每个候选产品应进入一期、二期、远期，还是取消/观察？ | 逐项交叉检验客群与支付证据、空间容量、价格和成本、运营主体、投入不可逆性及其对一期记录的依赖。 | 一期基础、二期扩展、远期战略、取消/保留观察四类产品清单，以及每项的改判条件。 |
| 12. 分期实施与动态修正 | 如何以较低不可逆投入开始，并根据结果扩大、调整或停止？ | 只能从“一期基础产品”中组合一期；把一期做成含界面、内容、空间、组织和记录的完整闭环；按资源成熟度、市场验证、建设周期和资金节奏设定阶段门。 | 一次可上会的一期决策包，以及后续扩大、调整、收缩或停止的条件。 |

## 叙事纪律

1. 从“值得解决的公共/区域问题及其机会窗口”开场，先让读者看到项目创造的价值，再说明为兑现这一价值所需的边界与投入。
2. 每个反例都必须改变候选路径、资源优先级、产品强度或阶段门。反例不是独立的风险清单。
3. 第 7 至 12 步只能是前 1 至 6 步的结果。第 12 步的一期单元还必须是第 11a 步的一期基础产品。若某个定位、活动、业态、空间概念或预算找不到上游输入，删除或回到上游重推。
4. 一期必须同时体现产品、空间、组织和财务四条线，而不是只留下调研、访谈、展板或服务窗口。
5. POI、路网、人口、夜光与 H3 是第 2 至 5、9 步的比较证据：分别说明供给、可达、居住背景、时段环境和空间分布；不得把它们改写成真实客流、支付、营收或许可结论。

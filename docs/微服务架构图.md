## 服务边界说明

- **`gaode-map-app`**：当前核心应用服务，承载 FastAPI、前端静态入口、API 聚合、领域 facade 与导出编排。
- **`search`**：独立容器服务，向主应用提供本地 POI / 查询能力，Compose 中通过 `LOCAL_QUERY_BASE_URL=http://search:8001` 访问。
- **`valhalla`**：独立路径与等时圈服务，主应用通过 `VALHALLA_BASE_URL=http://valhalla:8002` 调用。
- **`overpass`**：独立 OSM 查询服务，路网分析通过 `OVERPASS_ENDPOINT=http://overpass/api/interpreter` 访问。
- **外部服务**：高德、天地图、LLM Provider 与远端配置/数据源不归仓库部署管理，但属于运行时依赖。

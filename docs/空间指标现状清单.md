# 空间指标现状清单

这是第一轮“现有指标”盘点，不是最终语义目录。机器可读目录位于 `skills/spatial-business-analyst/references/metric-catalog.yaml`。

## 盘点口径

- `implemented`：后端或模块稳定计算并出现在 API/分析结果中。
- `implemented_geometry`：输出的是空间几何及其参数，不是一个单一数值。
- `implemented_proxy`：代码已计算，但它是代理等级，不能直接改写成业务事实。
- `derived_frontend`：前端根据后端结果和当前批次阈值派生，跨批次比较前需要重新确认口径。
- `planned_not_found_in_current_code`：设计材料提出过，但本轮未在当前代码中找到对应稳定输出。

## 当前明确不应当当作“已实现指标”的项目

本轮实现或收敛结果：POI 核密度复用现有前端热力图；夜光空间连续性、夜光与 POI/路网重叠、交叉口密度、网格综合活动指数已通过统一派生指标接口产出并接入“指标”导航。开闭店率与步行绕行系数仍受输入数据限制；多时间阈值等时圈仍需下一轮接入批量计算。

## 使用提醒

这份清单只回答“系统现在有什么”。下一轮再为每个指标补齐统一的 `definition / formula / higher_means / can_support / cannot_prove / valid_comparisons / preferred_baseline / combine_with / quality_requirements`，并据此建立分析组合规则；不要在本轮目录之外自行推断需求、客流、饱和度或商业机会。

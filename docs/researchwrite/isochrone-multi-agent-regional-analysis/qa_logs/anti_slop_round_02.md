# 第 2 轮语言与格式检查

## 检查结果

- 空泛意义表达：未发现“具有重要意义”“填补空白”“提供理论基础”“具有广阔应用前景”。
- 无依据强化词：未发现用“显著、全面、深入、有效提升”描述尚未完成的实验结果。
- 机械结构：正文中的“先、再、最后”只用于解释真实工作顺序，予以保留；未使用密集的“首先、其次、再次”搭建空洞段落。
- 主张强度：H1-H4 均保留为待验证假设；单次成功运行只表述为工程可行性证据。
- 可读性：在摘要前增加“一句话说明”；长方法段落拆分；六类数据以“能回答什么/不能推出什么”解释。
- 术语：POI、H3、等时圈、多智能体、基线与消融均在首次使用附近得到解释。

## Main risks

1. 当前可行性证据来自单个主案例，不能支持跨城泛化。
2. “高质量报告”需要在预实验中检验量表可操作性，避免指标之间重复计分。
3. MultiCa 与 N8N 的实现条件可能不匹配，不能直接作为因果对照。
4. 正式投稿前需要扩大规划、GeoAI、可达性和自动报告生成相关文献覆盖。

## Required fixes before final submission

- 锁定目标期刊或开题模板。
- 建立案例纳入标准、数据版本清单和专家盲评手册。
- 对自动指标进行人工复核，确定可接受误差范围。
- 预实验后进行样本量或统计功效设计。

## Recommendation

Foundation 可进入 proposal 初稿阶段。当前版本适合导师讨论研究方向，不适合作为最终投稿或基金申请文本。

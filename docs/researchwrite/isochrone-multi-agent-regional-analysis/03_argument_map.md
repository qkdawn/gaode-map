# Argument map

## Scientific tension

- What is known: 等时圈能够表达网络时间可达范围，多源空间数据能够刻画城市设施、人口、道路结构和活动代理；规划领域模型和地理空间智能体也已证明数据库检索、专门工具与工作流表示具有价值。
- What is unknown: 现有研究尚不能回答，多源空间数据库如何在同一等时圈范围内被专业智能体持续查询、校验和综合，并形成可核验的长篇区域分析报告。
- Why the gap matters: 如果空间范围、数据口径和生成过程不受控制，报告可能同时具备流畅叙事和错误空间关系，难以被规划人员复核或复用。

## Central research question

在相同项目输入和模型条件下，以等时圈为统一空间范围、通过受控工具接入多源空间数据库并采用专业多智能体工作流，是否能够提高区域分析报告的空间一致性、数值正确性、证据可追溯性、分析完整性和专家可用性？

## Central thesis

本研究假设，报告质量的关键不在于增加生成篇幅或智能体数量，而在于把空间范围构建、数据库查询、指标计算、专业解释与报告装配组织为可追溯的工作流；该假设需要通过匹配基线、模块消融、重复运行和专家盲评验证。

## Supporting arguments

### Argument 1: 等时圈提供可计算的共同空间边界

- Claim: 真实网络等时圈能够把设施、人口、道路和夜光数据约束在同一可达范围内，并暴露入口、路网和阈值对结果的影响。
- Evidence: [1] 及当前项目的等时圈分析链路。
- Limitation: 等时圈仍依赖起点、入口、出行方式、速度和路网数据质量，不代表真实到访。

### Argument 2: 数据库工具能够把空间事实与语言解释分开

- Claim: 先完成结构化查询与指标计算，再由智能体解释结果，有望降低数值漂移、范围混用和无来源判断。
- Evidence: [2]、[5]、[7] 及当前工作流的 `analyze_spatial_evidence`、项目文档分页读取、决策备忘录与最小来源持久化能力。
- Limitation: 工具存在不等于模型会正确调用，必须评估调用正确率和静默错误。

### Argument 3: 专业多智能体能够覆盖区域分析的不同决策维度

- Claim: 将供给、客群、交通、空间、运营和风险等任务交给边界明确的专业智能体，并保存阶段状态，有望提高分析覆盖与跨章节连续性。
- Evidence: [6] 与当前 12 步工作流的端到端成功运行。
- Limitation: 分工可能引入重复、冲突和成本，必须与单智能体及无状态版本比较。

### Argument 4: 报告质量可以被拆解并测量

- Claim: 区域分析报告不应只由“读起来像不像专家”评价，而可通过空间范围符合率、数据库数值一致率、证据覆盖率、矛盾率、重复运行稳定性和专家盲评共同评价。
- Evidence: [3]、[5]、[7] 提供了基准化和证据级评价先例。
- Limitation: 专家可用性仍包含主观判断，需要预先定义量表并报告评审一致性。

## Counterarguments / alternative explanations

1. 产出改善可能主要来自更长提示词、更高模型预算或更多生成轮次，而非数据库和多智能体结构。研究将匹配模型、输入、预算并记录调用成本。
2. 报告更长可能被误判为更完整。评价将以覆盖的有效问题、可核验事实和矛盾数量为单位，而非字符数。
3. 单一长沙案例可能对系统有利。研究将加入不同城市形态、不同等时圈阈值和数据缺失条件下的压力测试。
4. 规划专家偏好可能影响盲评。研究将使用多名评审、隐藏系统来源并报告一致性。
5. MultiCa 产出较弱可能来自实现配置差异。其结果只能作为探索性基线，不能支撑普遍方法结论。

## Final move

proposal 请求批准的不是“自动生成高质量规划报告”这一既定结论，而是一套能够检验该目标是否成立的方法、基准和评价协议。

# Style guide

- Language: 中文正文，保留必要英文术语与论文标题
- Target reader: 城市规划、城市计算、GeoAI 与智能体系统交叉领域的导师或内部评审者
- Tone: scientific-question-driven；方法具体，结论审慎
- Canonical terminology:
  - 等时圈
  - 多源空间数据库
  - 数据库增强多智能体方法
  - 区域分析报告
  - 空间一致性
  - 证据可追溯性
  - 专家可用性
- Forbidden expressions:
  - 赋能、智慧大脑、全方位、革命性、填补空白
  - 未给出比较与统计依据时使用“显著提升”“全面优于”“高质量”
  - 将“生成报告”写成“完成规划决策”
  - 将代理指标写成真实需求或因果机制
- Preferred expressions:
  - “本研究拟检验……”
  - “当前运行证明链路可执行，但尚不能证明……”
  - “在匹配模型、输入与预算的条件下比较……”
  - “该结论适用于……范围，超出该范围仍需验证”
- Citation style: proposal 阶段采用顺序编码制 `[n]`；正式投稿时按目标期刊转换

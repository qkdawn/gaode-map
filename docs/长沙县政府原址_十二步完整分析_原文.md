## `step_01_policy_site`：政策与场地

### 本步结论

项目首先是一个“保护、安全、居民共生”的城市更新项目，其次才是文旅或商业项目。

当前可进入策划的方向是：**保护建筑群活化 + 公共文化服务 + 居民环境改善 + 有限经营配套**。  
当前不能进入的方向是：整体商业化、整体住宿化、大拆大建和依赖深夜消费的运营模式。

### 1. `public_mission`

| 公共任务 | 证据性质 | 项目必须兑现的动作 |
|---|---|---|
| 保护历史建筑本体、格局和环境 | 法定要求 | 核验保护名录、保护范围、建设控制要求；建立一栋一档，先审查后设计 |
| 消除建筑安全与消防隐患 | 使用前置条件 | 完成结构检测、屋面与墙体病害调查、消防评估、水电管线和疏散核查 |
| 改善原有居民生活条件 | 项目现实责任 | 保留居民正常通行，补充消防、排污、无障碍和公共环境，不能默认整体搬迁 |
| 传承县政府原址历史 | 项目资源形成的公共任务 | 保存县委楼、民政楼、宣教楼、礼堂、档案楼等之间的历史关系，开展档案和口述史工作 |
| 形成可持续活化利用 | 省级政策导向 | 在真实性、完整性和安全边界内导入公共文化与有限经营，不以经营反向突破保护要求 |
| 建立社会参与机制 | 法规及居民现实共同要求 | 保护方案听取意见；居民参与通行、噪声、开放时间和公共空间管理规则制定 |

依据包括[《长沙市历史文化名城保护条例》](https://www.csrd.gov.cn/web/article/351b6a2c5ea34b73912d2095987f9495)及[《湖南省历史文化和文物保护国土空间专项规划》](https://www.hunan.gov.cn/hnszf/xxgk/wjk/szfbgt//202404/t20240407_33270548.html)。其中，“城市文化会客厅、文商旅居融合创新区”来自项目策划材料，不属于法定政策任务。

### 4. `opportunity_paths`

**路径 A：公共文化与社区更新主导，当前优先**

以安全修缮、原址展陈、礼堂公共文化、居民共享空间和庭院改善为核心。它最符合建筑群、集体记忆和居民仍在场的真实条件，审批和运营风险相对可控。

前提是明确公共投入主体、保护责任主体、居民协商机制和可开放建筑清单。

**路径 B：保护活化与轻度经营复合，条件性保留**

在路径 A 的基础上配置低油烟餐饮、文创、工作室、预约活动和机构合作，用经营收入补充日常运营。

前提是商业面积服从保护、安全和居民边界；租户不得自行改变结构、立面和设备系统。该路径不能先招商、后补审批。

**路径 C：整体文商旅综合体或夜间目的地，当前降级**

该路径需要较大的连续经营面积、明确产权、独立访客流线、较高消防容量及较低居民冲突。现有证据与这些条件相反，因此不能作为当前主方案。

只有居民及产权问题闭合、结构消防通过、实际夜间测试无明显冲突后，才可局部重新评估，不应整体升级。

### 5. `fatal_or_pending_checks`

**立即否决条件**

- 正式保护名录、保护范围或审批意见不允许拟议用途及改造方式。
- 结构检测认定核心建筑无法在合理工程条件下开放。
- 消防疏散无法在不破坏保护本体的情况下成立。
- 项目方无法取得必要的产权、使用权或公共通行权。
- 居民消防通道、日常通行与访客运营无法分离。
- 改造必须依赖拆除核心历史构件或破坏整体格局。

**必须核实但可通过设计或分期处理**

- 102 户与 120 户口径，由街道、产权登记和逐户调查统一。
- 13 栋建筑面积、边界和权属，由测绘及不动产资料确认。
- 建筑病害，由结构、文保和消防专业单位分栋评估。
- 华夏路第二入口，由红线、产权、交通和消防条件联合验证。
- 停车不足，优先通过公共交通、预约和外围共享停车管理，不以拆除庭院解决。
- 噪声与开放时间，通过居民基线调查和小规模试运营建立规则。

### 6. `handoff`

第 2 步“区域角色”必须遵守以下边界：

1. 不得把项目预设成城市级文旅目的地。
2. 必须同时比较“社区公共文化节点”“县政历史记忆节点”“商圈文化配套”三种角色。
3. 区域角色必须服务保护修缮和居民改善，不能要求场地为流量牺牲公共任务。
4. 不得使用约 2 万㎡推导经营规模，也不得假设 8 栋建筑全部开放。
5. 不得将邻近商场、地铁和文化机构解释为已经形成客流或合作关系。
6. 第二步需要回答的核心问题是：**这个项目在周边已有商业、医院、寺庙和文化设施之间，究竟承担哪一种不可替代的区域功能。**

### 4. `selected_role`

**主角色：社区共生型县政历史文化节点。**

成立依据：

- 场地拥有成片县政建筑、礼堂、档案楼和历史路径，而非单一空置物业。
- 三栋住宅仍有人居住，公共服务和居民环境改善是绕不过的任务。
- 周边已有商场、影院、文化站和图书馆，项目无需复制一般商业或普通社区活动室。
- 项目能够提供的不可替代内容，是“长沙县政府原址及其工作、生活和城市变迁”。

**次角色：城市北部文化线路的内容中继点。**

该角色只有在以下条件成立后才能使用：

- 开福寺、商场、影院、湖南博物院或学校形成书面合作与联合活动。
- 实测从地铁、商业节点到项目的步行和过街条件可接受。
- 项目形成稳定开放时间、预约制度和可识别的原址内容。
- 联合活动记录显示确有跨节点到访，而不是宣传层面的“联动”。

**阶段性升级方向：小型特色目的地。**

它可以成为具有专门到访理由的微型目的地，但不以大客流为目标。升级依据应是项目自身的复访、预约、活动和内容传播数据，而不是长沙游客量或周边POI数量。

### 5. `rejected_roles`

**独立城市级文旅目的地：当前排除。**

反证包括：建筑安全和开放范围未确定、居民与访客流线未解决、没有正式运营内容、没有到访数据、距地铁仍有最后一段步行。城市级地标定位会迫使项目追求容量、频次和夜间强度，与第一步的保护及居民边界冲突。

**商圈消费承接区：不作为主角色。**

华创和富兴已经拥有购物、影院、餐饮和亲子设施。项目若以承接溢出消费为主，会进入同类竞争，并弱化原址内容。商业联动只能服务文化内容，不能取代主角色。

**产业服务平台：当前排除。**

公司企业POI数量只反映记录构成，不能证明产业链、办公规模或企业服务需求。没有企业访谈、产业规划和集群关系前，不应提出文创园、总部基地或数字媒体产业园。

### 6. `capability_requirements`

要让主角色真正成立，项目必须具备：

- **吸引能力：** 正式核验的原址历史、建筑档案、口述史和可持续更新的展陈内容。
- **日常服务能力：** 居民议事、阅读、社区活动和小型公共文化空间，而非只在节庆开放。
- **到达能力：** 从开福寺站、华创、富兴和潘家坪路的实际步行调查、过街核查及连续导视。
- **承接能力：** 厕所、无障碍、消防、安保、预约、恶劣天气和居民分流机制。
- **协同能力：** 与文化站、学校、商场、影院和文化机构建立具体活动，而非只签战略框架。
- **验证能力：** 记录访问来源、到达方式、进出时间、活动参与、复访和居民投诉。

### 7. 降级路径

如果跨节点合作和外来访问始终无法成立，项目不需要被判定失败，而应降级为：

**以居民服务、原址档案、社区展陈和低频公共活动为主的社区文化场所。**

这一角色对外部客流依赖较低，也更符合保护修缮和居民共生的底线。

### 8. `handoff`

第3步“市场与流动”需要验证：

1. 周边居民、办公人群、商场使用者和文化访问者是否真的构成不同客源。
2. 开福寺站、华创和富兴方向是否存在连续、安全的实际步行流线。
3. 开福寺、影院、文化站和湖南博物院的使用者是否有跨节点活动可能。
4. 日常社区使用与周末外来访问在时间上能否分开。
5. 医院相关流动是否仅形成陪护、住宿和便民需求，避免误判为文化消费。
6. 项目应优先测试本地日常使用，还是预约制城市文化访问。

第2步质量门已通过。下一项为 `client-decision-market-flow`。

## `step_03_market_flow`：市场与流动

### 本步结论

项目具备较大的区域市场背景和多个潜在到达来源，但目前**没有证据证明这些人会进入项目**。

当前最可靠的市场转化机制是：

1. 周边居民形成日常复访。
2. 学校、社区和文化机构形成预约制到访。
3. 华创、富兴、影院和地铁方向形成活动驱动的顺路到访。

“承接湖南博物院或开福区旅游客流”只能作为中长期假设，不能进入一期客流预测。

### 4. `conversion_mechanisms`

**机制A：社区复访**

通过居民议事、阅读、口述史、亲子活动和日常公共空间形成低频但持续使用。

- 项目可控制：内容、开放时间、预约、居民参与和空间规则。
- 项目不可控制：居民个人兴趣、家庭结构和空闲时间。
- 失败信号：活动仅由组织动员、没有自主报名或复访，居民投诉持续增加。
- 当前优先级：最高。

**机制B：机构预约**

由学校、街道文化站、社区组织或企事业单位预约原址导览、工作坊和小型公共活动。

- 项目可控制：课程、讲解、接待标准、时间和合作报价。
- 项目不可控制：机构预算、采购周期和课程安排。
- 失败信号：只有意向沟通，没有付费、排期或实际到场。
- 当前优先级：较高。

**机制C：商场及影院联动**

使用联名展览、票根活动或联合传播，把华创、富兴和影院使用者引向项目。

- 项目可控制：联动内容、活动日期、导视和预约入口。
- 项目不可控制：商场客流结构、影院排片和合作方推广资源。
- 失败信号：曝光量增加但项目到场来源没有变化。
- 当前优先级：测试性。

**机制D：文化线路串联**

把古开福寺、县政府原址、湖南博物院及其他文化节点组织为主题线路。

- 项目可控制：自身内容、讲解和预约。
- 项目不可控制：其他机构的开放制度、合作意愿及游客行程。
- 失败信号：线路只存在于宣传材料，没有跨节点签到。
- 当前优先级：中长期。

**机制E：自然经过转化**

依赖地铁、道路和周边商业经过人群临时进入。

这一机制最弱。项目不直接临地铁，也没有经过人流监测；保护建筑和居民环境也不适合依赖无预约的大规模随机进入。因此不能作为财务模型基础。

### 5. `season_time_conditions`

- 2025年五一数据证明开福区节假日文旅活动会集中放大，但项目容量和居民承受力未知，不应直接追求同类假日峰值。
- 湖南博物院通常周二至周日9:00–17:00开放，若进行内容联动，首先应测试日间和傍晚早段，而不是深夜。
- 工作日日间可能对应居民、学校和机构活动；周末可能对应家庭及预约访客。这只是测试分组，不是已验证需求。
- 夜光数据不能说明实际人流。夜间活动必须另行记录到达方式、散场、照明、投诉和交易。
- 三个庭院受天气影响，所有户外测试应有室内备选；当前没有季节利用记录。
- 当前没有停留数据，不能写“适合半日游”“停留1–2小时”等结论。

### 6. 首轮市场验证设计

在正式产品设计前，应建立以下记录：

| 记录 | 用途 |
|---|---|
| 报名来源：居民、社区、学校、商场、自然报名 | 判断真正客源 |
| 到达方式及起点 | 验证地铁、商场和社区流动链 |
| 首次与复访标识 | 区分一次性好奇与持续使用 |
| 入场、离场时间 | 建立真实停留分布 |
| 参加内容和拒绝原因 | 判断内容与服务缺口 |
| 联动活动代码或票根 | 验证合作方是否带来实际到场 |
| 居民投诉、噪声和通行事件 | 判断市场活动是否突破场地边界 |
| 活动成本、交易和退款 | 为后续运营与财务步骤提供直接证据 |

首轮不预设客流阈值。先建立不同活动和时段的基线，再由业主、运营方、街道和居民代表共同确定扩大、调整或停止条件。

### 7. `data_limits`

- 当前“15min”范围缺少交通模式、速度和正式入口说明，不能等同于真实15分钟步行圈。
- 58,057人为人口格网面积加权估计，采用格内均匀分布假设，不是人口登记数据。
- 2024年POI说明设施位置与分类，不说明营业状态、容量、质量和使用量；地址字段仍为空。
- 道路句法指标不是行人或车辆计数。
- 2025年夜光不是人流、营业时间、消费或安全数据。
- 开福区景区人次和湖南博物院观众属于其他统计对象，不能转换成项目客流。
- 当前没有项目开放、票务、签到、门禁、轨迹、访谈或交易记录，因此所有转化机制仍是候选。

### 8. `handoff`

第4步“供给缺口”必须比较：

1. 周边已有餐饮、购物、影院、培训、社区文化和住宿分别提供什么。
2. 同一范围内哪些设施与项目重复，哪些可以合作。
3. 文化设施数量与具名设施的真实功能是否一致。
4. 市场缺口究竟是“没有设施”，还是“缺少县政原址内容与居民共生场景”。
5. 医院、商场和住宿形成的供给不能混合解释为文旅需求。
6. 只有能对应社区复访、机构预约或内容联动机制的缺口，才能进入下一步客群和产品分析。

第3步质量门已通过。下一项为 `client-decision-supply-gap`。

## `step_04_supply_gap`：供给缺口

### 本步结论

项目真正的供给空位不是“附近缺少餐饮、咖啡、影院或住宿”，而是：

**缺少一个以长沙县政府原址为事实载体，同时完成历史解释、居民共建和小型公共文化活动的场所。**

这一空位来自项目独有的建筑群和社区关系，较难被普通商业复制。项目应填补“内容与公共服务断点”，而不是填补泛化业态数量。

### 3. 数据揭示的供给结构

**普通消费供给占据主要构成。**

餐饮681条、购物585条，两类合计占全部POI约48%。这说明用户在范围内已有大量日常消费选择，项目若只增加普通餐饮和零售，很难从场地自身形成区别。

**文化分类数量不能直接代表文化内容质量。**

科教文化146条中，科教文化场所61、培训机构39、学校22，占据主要部分。真正明确为文化宫、图书馆、美术馆的记录合计仅5条。

更重要的是，唯一“博物馆”分类记录名为“长沙龙渊传媒”，名称与分类明显不一致。因此不能用“1座博物馆”支撑供给判断，也不能简单写成“博物馆稀缺”。

**影院和娱乐供给已经具名成立。**

4条影剧院均能对应具体名称；28条娱乐场所包含KTV、棋牌、酒吧等。这意味着项目没有必要用普通娱乐设施证明活力，尤其不能在居民与保护建筑约束下复制高噪声业态。

### 4. `unmet_jobs`

**任务一：让居民和公众理解“这里为什么值得保留”。**

- 受影响对象：原址居民、周边社区、学校及初次访问者。
- 现有供给为何未解决：商场、影院、图书馆和文化站均不承担县政府原址的系统解释。
- 项目凭什么解决：历史建筑、礼堂、档案楼、行政建筑关系和居民记忆均在原址。
- 所需证据：正式建筑历史、档案、照片、口述史和保护认定文件。

**任务二：在不搬离居民的前提下形成公共文化使用。**

- 受影响对象：项目居民及周边社区。
- 现有供给为何未解决：公共文化设施位于其他地点，不能改善原址内部的庭院、通行和社区关系。
- 项目凭什么解决：居民、住宅、庭院和公共建筑处于同一场地，可形成分时共享。
- 所需证据：居民需求、愿意参与的活动、安静时段、禁入边界和投诉基线。

**任务三：为学校与机构提供原址型教育内容。**

- 受影响对象：学校、社区组织及文化机构。
- 现有供给为何未解决：培训机构和学校提供课程，但缺少与县政历史、城市治理及近现代建筑结合的现场内容。
- 项目凭什么解决：建筑本体可成为教学材料。
- 所需证据：教师访谈、课程适配、机构采购流程和真实预约。

**任务四：连接商业娱乐与公共文化，而非继续增加商业。**

- 受影响对象：华创、富兴、影院使用者及合作运营方。
- 现有供给为何未解决：商业设施能够聚集活动，但其内容以消费和娱乐为主。
- 项目凭什么解决：提供短时原址展览、城市故事和公共活动，形成内容补充。
- 所需证据：联合活动、来源代码、票根和跨节点签到。

**任务五：提供可持续、低扰动的历史建筑使用方式。**

- 受影响对象：业主、居民、保护责任主体和运营方。
- 现有供给为何未解决：普通餐饮、酒店和娱乐需要的设备、噪声及营业时间可能与保护和居住冲突。
- 项目凭什么解决：可采用预约、小班、日间及室内低噪声模式。
- 所需证据：消防容量、建筑可用清单、活动成本和居民反馈。

### 5. `gap_options`

**路径A：填补原址内容空缺**

建设县政府原址档案、展陈、口述史和建筑导览体系。

- 对应市场机制：目的性到访、机构预约。
- 核心能力：研究、策展、档案授权、讲解和内容更新。
- 可守性：较高，因为内容依赖原址和真实建筑。
- 失败风险：历史资料不足，最终只剩装饰性怀旧。

**路径B：连接公共文化服务断点**

将礼堂、庭院和部分建筑用于居民活动、学校课程、社区展览及小型论坛。

- 对应市场机制：社区复访、机构预约。
- 核心能力：社区协商、日常排期、无障碍和低扰动管理。
- 可守性：中高，依赖居民关系与场地组织。
- 失败风险：公共空间只有开业活动，缺少持续使用。

**路径C：成为商业与文化之间的内容节点**

与华创、富兴、影院、图书馆和文化站联合策划，不承担大型商业功能。

- 对应市场机制：商场联动、文化线路。
- 核心能力：合作策划、联合传播、来源追踪和稳定开放。
- 可守性：中等，活动形式容易被复制，但原址内容不可复制。
- 失败风险：合作停留在曝光，没有实际跨节点到访。

**路径D：以餐饮、文创和住宿填补经营收入**

只能作为前三条路径的配套，不能独立构成供给空位。

- 普通咖啡、茶饮和餐饮的复制风险高。
- 住宿需要较大工程、消防和持续服务能力，并面对已有151条住宿记录。
- 当前不具备将其提升为主路径的需求和财务证据。

### 6. `false_gaps`

以下说法目前均不成立：

- **“周边没有博物馆。”** 当前博物馆分类记录失真，湖南博物院又位于当前范围之外但邻近，需按不同空间尺度表述。
- **“缺少咖啡和茶空间。”** 范围内有17家咖啡厅、16家茶艺馆及多个明确品牌；项目只能做内容型配套。
- **“缺少餐饮。”** 681条餐饮记录足以证明类型重复，但不能证明容量饱和。
- **“缺少影院和夜间娱乐。”** 4家具名影院、28条娱乐场所已经存在；项目不宜复制。
- **“缺少住宿。”** 151条住宿记录说明供给线索较多，但入住率和客源未知。
- **“停车场很多，所以停车充足。”** 173条停车场记录可能包含出入口和同一停车设施的重复点位，且没有泊位与余量。
- **“科教文化设施很多，所以公共文化成熟。”** 146条记录主要由泛文化场所、培训和学校组成，不能代替公共文化质量。
- **“公司企业多，适合做产业园。”** 287条企业记录没有形成产业链和需求证据。
- 所有POI的`address`均为空，因此不能进行门牌、楼层和沿街界面判断。

### 7. 当前选择

建议将路径A与路径B合并为核心增量价值：

> 以县政府原址研究和展陈为内容核心，以居民共享和公共文化活动形成持续使用。

路径C作为放大机制，不能成为主产品。路径D只能在保护、安全、居民和真实交易测试通过后局部配置。

这修正了第2步的区域角色：项目不是泛化的“文化中继站”，而应首先拥有**只有该原址能够提供的内容与社区关系**，之后才有资格参与区域联动。

### 8. `handoff`

第5步“客群与使用”需要验证：

1. 居民究竟需要环境改善、议事、休闲、展陈还是其他服务。
2. 周边家庭和老年人是否愿意持续使用，而非一次性参观。
3. 学校、文化站和社区组织需要什么课程、场次和采购方式。
4. 原址历史内容对普通市民、县政相关群体和城市文化访问者是否具有不同吸引力。
5. 商场、影院与酒店使用者是否存在可验证的联动情境。
6. 哪些人群与活动会造成噪声、通行和居民冲突。
7. 泛餐饮、住宿和娱乐不作为预设客群需求，必须由行为及交易数据重新证明。

第4步质量门已通过。下一项为 `client-decision-audience-use`。

## `step_05_audience_use`：客群与使用

### 本步结论

项目不应先定义“年轻游客”“文旅消费者”等宽泛客群，而应优先服务三类可验证任务：

1. **场地居民：** 在保持正常生活的前提下改善环境、参与场地治理和保存集体记忆。
2. **周边社区与家庭：** 获得可反复使用的低扰动公共文化空间。
3. **学校及机构：** 取得与县政历史、城市变迁和近现代建筑相关的原址课程与活动。

城市文化访问者是次级客群；商场、影院、酒店和医院相关人群只能作为测试来源，不能作为项目基本盘。

### 1. 人口证据的正确使用

2026年人口数据包含439个与范围相交的格网：

- 面积加权总人口约58,057人，采用“格网人口 × 与范围重叠比例”计算。
- 全部相交格整格求和约71,615人，因包含边界格，不能作为项目人口规模。
- 整格人口中，5–19岁约10,100人，占14.1%。
- 30–39岁约14,995人，占20.9%。
- 50–64岁约15,933人，占22.2%。

后三组比例只能描述相交格人口构成，未进行范围面积加权。它们分别提示青少年教育、家庭参与和中年社区文化使用的测试方向，不能证明需求强度、支付意愿或到访频率。

### 2. `audience_options`

#### A. 场地居民：权利相关者与首要使用者

- **对象：** 材料称约102户，另有120户冲突口径的三栋住宅居民。
- **触发情境：** 日常出入、庭院使用、环境改善、居民议事、邻里活动。
- **待完成任务：** 安全通行、不被游客干扰、获得适用的共享空间、参与决定开放规则。
- **当前替代：** 现有住宅公共空间和周边社区设施。
- **主要阻碍：** 产权差异、噪声、陌生人进入、消防、停车及担心被经营活动挤出。
- **价值交换：** 项目改善环境和公共服务；居民提供意见、共同维护和自愿的口述史。
- **支付机制：** 不应以消费支付为前提。
- **反证：** 居民明确拒绝共享、不同住宅利益无法协调，或运营持续影响通行与休息。

居民不是需要被“转化”的消费者，而是任何客群方案必须先满足的治理主体。

#### B. 周边社区家庭：核心候选使用者

- **对象：** 周边家长、儿童和多代家庭，年龄结构及学校、幼儿园、亲子设施仅提供来源线索。
- **触发情境：** 周末家庭活动、社区节日、学校之外的地方文化学习。
- **待完成任务：** 在步行可达范围获得有内容、可共同参与、区别于商场培训班的公共文化体验。
- **当前替代：** 华创和富兴亲子设施、培训机构、影院、公园及社区文化站。
- **主要阻碍：** 项目尚未开放、内容未知、无正式入口、场地安全和卫生设施未确认。
- **价值交换：** 项目提供原址内容和共同活动；家庭贡献参与、反馈和适度服务付费的验证机会。
- **反证：** 只有免费首发活动有人参加，后续无自主报名或复访。

#### C. 学校、文化站和社会组织：核心候选采购者

- **对象：** 长沙师范附属天健小学（建设中）、伍家岭小学、麻园岭小学、湘雅路街道综合文化站、开福区文化馆等。
- **触发情境：** 原址课程、社会实践、社区展览、公共文化活动。
- **待完成任务：** 获得有明确教学目标、接待标准和安全保障的场地型内容。
- **当前替代：** 校内课程、湖南博物院、文化馆、少年宫及商业研学。
- **主要阻碍：** 项目没有课程、师资、保险、容量、厕所和消防方案。
- **价值交换：** 项目提供课程和场地；机构通过预约、采购、联合组织或内容合作履约。
- **反证：** 多轮接洽后没有课程试用、正式排期或负责人承诺。

POI中有22条学校记录，但“北京中建建筑设计院长沙分院”也被归入学校，说明分类存在误差。必须逐个核验具名机构。

#### D. 原县政府相关人员与历史见证者：内容共建客群

- **对象：** 原工作人员、居民、家属及了解长沙县原址历史的人。
- **触发情境：** 档案征集、口述史、旧照片辨识、纪念活动。
- **待完成任务：** 保存个人经历、核对历史事实、让其记忆获得公共表达。
- **当前替代：** 家庭保存、单位档案或零散叙述。
- **主要阻碍：** 名单尚未建立，版权、隐私和历史口径需要治理。
- **价值交换：** 项目提供档案保存和公共呈现；参与者自愿提供资料与证言。
- **反证：** 无法获得可靠资料，或不同叙述无法完成事实核验。

这类人数量可能不大，但对主题真实性的价值高于普通游客。

#### E. 城市历史文化访问者：次级增长客群

- **对象：** 已经访问古开福寺、湖南博物院或关注城市更新和建筑的人。
- **触发情境：** 主动预约原址导览、专题展览和小型活动。
- **待完成任务：** 看到综合博物馆和宗教景点之外，更具体的县政、建筑和生活史。
- **当前替代：** 湖南博物院、古开福寺、历史街区及线上内容。
- **主要阻碍：** 项目知名度低、距地铁仍有最后一段步行、没有成熟展陈。
- **价值交换：** 项目提供不可复制的原址体验；访问者通过预约、传播和可能的活动付费支持运营。
- **反证：** 访问者只对建筑拍照感兴趣，不愿参加完整内容或复访。

#### F. 商场、影院和餐饮使用者：条件性顺路客群

- **对象：** 华创、富兴、万达、保利影院及周边餐饮使用者。
- **触发情境：** 联名活动、票根、主题展览或商场传播。
- **待完成任务：** 在原有消费行程中增加不同类型的文化内容。
- **当前替代：** 商场内部亲子、娱乐、培训和餐饮。
- **主要阻碍：** 项目不在商业体内部，自然顺路关系未建立。
- **价值交换：** 联动优惠或活动内容；通过来源代码验证实际转化。
- **反证：** 有曝光和领券，但没有到场或完整参与。

#### G. 医院陪护、酒店住客和夜间娱乐人群：暂不作为核心

附近住宿和医院服务密集，但无法区分陪护、商务和游客。项目也不具备24小时服务、医疗配套或深夜娱乐条件。这些人只能通过后续访谈证明具体任务，当前不得推导产品。

### 4. `access_time_evidence`

**项目直接证据**

- 场地内居民确实存在并保持日常居住。
- 没有项目开放后的进出、停留、轨迹和活动记录。
- 因此没有任何已证实的客源半径和停留时间。

**空间代理证据**

- 华创约382米，万达约500米，富兴约504–617米。
- 开福寺地铁站约690米，湘雅医院地铁站约823米。
- 上述均为分析中心到POI的直线距离，不是入口到入口步行距离。
- 当前“15min”范围缺少交通模式、速度和正式入口说明，不能直接视为真实步行圈。

**外部运行证据**

- 湖南博物院具有稳定预约和开放制度，但属于其他机构。
- 开福区假日景区存在明显集中访问，但统计对象不是项目。
- 这些证据只能帮助设计测试时段，不能转换为项目行为。

**首轮测试参数**

不预设“半日游”或固定停留时长。分别测试：

- 工作日日间社区使用。
- 学校或机构预约活动。
- 周末家庭活动。
- 日间及傍晚早段的专题导览。
- 商业联动来源活动。

每次记录实际到达、进入和离开时间，再决定后续产品长度。

| 优先级 | 对象 | 选择理由 | 运营要求 |
|---|---|---|---|
| 权利优先 | 场地居民 | 决定项目能否成立，不以支付为目标 | 居民协商、通行和安静边界 |
| 核心一 | 周边社区家庭 | 与社区节点角色和公共文化缺口一致 | 可重复内容、低门槛、安全 |
| 核心二 | 学校、文化站和社会组织 | 可通过预约和履约直接验证 | 课程、接待标准、负责人 |
| 内容优先 | 原工作人员及历史见证者 | 决定原址叙事真实性 | 档案、隐私、口述史治理 |
| 次级增长 | 城市历史文化访问者 | 可放大项目影响，但不构成当前基本盘 | 预约导览、持续内容 |
| 条件性 | 商场和影院使用者 | 距离较近，但转化未经验证 | 联合活动、来源追踪 |
| 暂不选择 | 医院陪护、普通酒店住客、深夜娱乐人群 | 任务与项目主角色不清或冲突 | 取得直接证据后再评估 |

### 6. `validation_design`

建议用一个连续的首轮试运营周期进行验证，候选周期为4–6周。该周期是测试参数，不是经营结论。

**招募渠道**

- 场地居民：逐户邀请与居民会议，先统一102/120户台账。
- 周边社区：街道、社区群和现场报名。
- 学校机构：选择学校、文化站和社会组织进行定向邀约。
- 文化访问者：预约页面及城市文化社群。
- 商业联动：华创、富兴或影院专属来源代码。

**每次必须记录**

- 匿名参与者类型和招募渠道。
- 首次到访或复访。
- 同行关系。
- 实际起点、到达方式和到达困难。
- 预约、到场、取消和拒绝原因。
- 入场与离场时间。
- 使用空间和参与内容。
- 是否完成活动、是否愿意再次参加。
- 支付、退款或机构履约情况。
- 居民通行、噪声、安全和投诉事件。

**推翻假设的信号**

- 居民多轮参与后仍无法形成共享规则。
- 家庭使用只依赖免费首发，取消免费后完全消失。
- 学校和机构没有任何负责人愿意进入试课或采购流程。
- 历史访问者认为内容可由线上资料完全替代。
- 商业联动产生曝光但没有可识别到场。
- 傍晚活动持续产生居民投诉或散场风险。
- 项目必须依赖高噪声、深夜或大容量活动才能维持使用。

阈值应在取得首轮基线后，由业主、运营方、街道和居民代表共同审批，不在当前凭经验编造。

### 7. 当前选择

一期应围绕四种关系组织，而不是围绕年龄标签：

> 居民共同治理、社区持续使用、机构预约履约、历史见证者共同生产内容。

城市文化访问和商业联动用于放大，不用于定义项目基本盘。医院、住宿和深夜娱乐人群暂不进入主题与产品设计。

### 8. `handoff`

第6步“主题资源”必须回应：

1. 居民需要被尊重为在场生活者，而不是历史布景。
2. 周边家庭需要可理解、可参与、可复访的地方故事。
3. 学校需要能够转成课程目标的真实建筑和历史材料。
4. 历史见证者需要严谨的档案、署名、隐私和多口径表达机制。
5. 城市访问者需要区别于湖南博物院和古开福寺的独特内容。
6. 主题必须来自县政府原址、行政建筑、礼堂、档案和居民生活，不能只套用泛湖湘、泛红色或“网红长沙”概念。
7. 任何夜间主题均须服从居民、保护和散场条件。

第5步质量门已通过。下一项为 `client-decision-theme-resources`。

## `step_06_theme_resources`：主题资源

### 本步结论

建议主主题为：

# **从县政大院到城市共同体**
**一座县政府原址中的工作、生活与城市变迁**

它不是只讲政府机构，也不是把居民生活当作附属背景，而是解释：

> 行政机构如何留下建筑，建筑如何承载集体工作与生活，职工宿舍如何经过房改成为居民家园，而今天的保护更新又如何重新协商公共性与日常生活。

“近现代建筑修缮”作为支撑主题；“潘家坪红色历史”只能作为片区背景或线路内容。泛湖湘、泛红色、非遗工坊和当代潮流不能成为现阶段核心主题。

### 1. `resource_system`

#### 核心资源

| 资源 | 当前事实 | 主题价值 | 证据状态 |
|---|---|---|---|
| 县委楼、民政楼、宣教楼 | 材料称为核心办公建筑 | 说明县政机构如何组织和运行 | 建筑名称和历史功能需档案核验 |
| 农水楼、档案楼、活动中心 | 材料称为行政配套建筑 | 可讲公共事务、档案和组织生活 | 需核验原始用途、年代及变更 |
| 礼堂 | 位于三个庭院东侧，是材料认定的空间焦点 | 集体会议、文化活动和共同记忆的核心场景 | 扇形观众席、木屋架等需测绘确认 |
| 县政府大门至县委楼约120米路径 | 材料明确提出 | 可把不同建筑和行政功能组织成连续叙事 | 当前只是策划识别，不是批准流线 |
| 礼堂西侧三个庭院 | 由办公、活动及住宅建筑围合 | 连接工作、集体活动和日常生活 | 开放边界需居民、消防和产权核验 |
| 三栋原职工宿舍 | 材料称1990年代完成房改，目前仍有居民 | 把机构史连接到住房制度、家庭和当代社区 | 102户与120户口径冲突 |
| 当前居民生活 | 入住率较高，不宜整体搬迁 | 使主题成为仍在继续的生活史，而非静态怀旧 | 使用个人故事必须取得知情同意 |

#### 支撑资源

| 资源 | 支撑作用 | 边界 |
|---|---|---|
| 长沙县正式历史沿革 | 提供县、市分治及行政区划变迁背景 | 未证明本建筑群的精确使用年代 |
| 红砖清水墙、坡屋顶、木构屋架等 | 支撑近现代建筑、材料和修缮叙事 | 构造与年代必须由测绘和检测确认 |
| 档案、旧照片、图纸和文件 | 可把建筑名称变成有证据的机构故事 | 当前尚未形成可用档案清单 |
| 原工作人员及居民口述史 | 补充工作流程和大院生活细节 | 不能以单一回忆替代档案事实 |
| 开福寺、湖南博物院及周边文化设施 | 提供区域文化背景和合作对象 | 不能替代项目自身主题 |
| 沈家大屋与潘家坪红色历史 | 可形成片区历史线路 | 不得表述为发生在县政府原址 |

长沙县人民政府发布的[《县域概况》](http://www.csx.gov.cn/zjxs/yxxs/xygk/202311/t20231128_11301245.html)确认了1933年长沙市、县分治以及后续行政区划变化，但没有确认该建筑群“1950–1996年”的完整使用史。

#### 场景资源

- 大门、主路径、办公建筑和礼堂形成从进入、行政办公到集体活动的空间顺序。
- 三个楔形庭院把行政建筑、活动中心和住宅联系在一起。
- 礼堂略高的地面和空间位置形成视觉焦点。
- 红砖、坡屋顶、墙体病害和修缮过程可转化为建筑观察内容。
- 宿舍间花园、大树、园艺和居民日常使用可形成“仍在生活的大院”场景。
- 档案楼可以承接档案整理、照片辨识和口述史工作，但具体功能需安全核验。

这些场景必须以真实构件和日常关系为基础，不宜使用大量仿旧布景覆盖原有空间。

#### 当前不可作为核心的资源

- **“长沙县千年文脉”：** 长沙县历史悠久，但没有证据证明两千多年历史连续发生在本场地。
- **“红色精神”：** 潘家坪片区确有1927年沈家大屋相关革命历史，但没有证据表明事件发生在县政府原址。
- **“长沙县非遗”：** 材料没有列出与项目直接相关的具体项目、传承人或历史关系。
- **“数字媒体”：** 是展示手段或行业，不是场地资源。
- **“年轻潮流”：** 是期望的市场形象，不是历史主题。
- **“精品酒店、特色餐饮”：** 是经营业态，不是文化资源。
- **“1950–1996年有县无城”：** 当前来自项目材料，官方页面尚未验证这一准确表述。
- **第四批历史建筑及一般不可移动文物身份：** 项目材料有陈述，但正式名录文件仍未取得。

### 2. `place_mechanism`

项目的地方性不是由单一历史事件产生，而由三组关系共同形成。

#### 机制一：行政功能留下可阅读的建筑关系

县委楼、民政楼、宣教楼、农水楼、档案楼并非随机建筑集合。不同机构名称、空间位置和礼堂共同记录了一套县政工作体系。

主题不能只展出“老照片”，还应回答：

- 不同部门分别处理什么公共事务。
- 档案如何形成和保存。
- 礼堂承担什么集体活动。
- 大门、主路、办公楼和礼堂为何如此组织。

#### 机制二：工作大院逐步转化为生活社区

原职工宿舍、1990年代房改和今天仍在居住的家庭，使场地经历了从单位空间到私人产权与社区生活的转变。

这意味着居民不是历史结束后的“遗留问题”，而是场地演变的一部分。更新项目必须同时解释公共记忆和私人生活如何共存。

#### 机制三：保护更新本身成为新的历史阶段

墙体开裂、屋顶渗漏、管线老化和消防不足既是工程问题，也反映建筑长期使用与维护的现实。

在安全允许的范围内，调查、测绘、修缮材料和决策过程可以被公开解释，使公众理解保护不是“刷旧做新”，而是在真实性、安全和继续使用之间作选择。

### 3. `theme_options`

#### 主题A：县政运行与城市变迁

**核心命题：** 通过原县政府建筑群理解县政机构、城市边界和公共治理的变化。

- 目标对象：学校、城市文化访问者、原工作人员。
- 独特证据：具名行政建筑、档案楼、礼堂和完整建筑关系。
- 场景：机构建筑导览、档案展、城市区划地图、原工作人员口述史。
- 运营承接：预约导览、课程、专题展和研究活动。
- 可复制风险：低，依赖原址。
- 反例：若档案不能证明建筑功能和使用年代，主题将退化为泛行政史。

#### 主题B：大院共同生活

**核心命题：** 展示工作、集体活动、宿舍、房改和当代居民如何在同一大院连续发生。

- 目标对象：居民、社区家庭、历史见证者。
- 独特证据：礼堂、宿舍、庭院、花园及当前居民。
- 场景：居民照片展、园艺、家庭记忆地图、社区议事和公共活动。
- 运营承接：居民共策、社区展览、日常共享空间。
- 可复制风险：中低，关系真实但依赖居民参与。
- 反例：若居民不愿参与或隐私无法保护，不能以“生活史”包装他们。

#### 主题C：近现代建筑与修缮课堂

**核心命题：** 让公众理解红砖建筑、坡屋顶、木构屋架和保护修缮。

- 目标对象：学校、建筑及城市更新关注者。
- 独特证据：成片建筑及真实病害。
- 场景：构造观察、材料样本、修缮档案和阶段性开放。
- 运营承接：课程、工作坊、专业交流和修缮记录展。
- 可复制风险：中等，其他历史建筑也可开展。
- 反例：若为了展示而暴露危险构件，或施工影响居民，主题与保护目标冲突。

#### 主题D：潘家坪红色记忆

开福区政府转载的[《开福：用“文化+”成就湖南“文化客厅”》](http://www.kaifu.gov.cn/zfxxgk/fdzdgknr/dtyw_qzf/kfyw/201807/t20180731_4549994.html)明确记载，1927年毛泽东和中共湖南省委曾在潘家坪沈家大屋召开会议。

- 证据能够支持“潘家坪片区存在重要红色历史”。
- 证据不能支持“会议发生在长沙县政府原址”。
- 在确认沈家大屋位置、保存状态及线路关系后，可以形成片区导览章节。
- 当前若直接设“红色印记区”，会造成历史地点误植。

因此不作为核心主题。

#### 主题E：湖湘文脉、非遗与当代创意生活

这一组合可以适用于长沙许多文化项目，无法解释为什么必须在县政府原址实施。非遗、数字媒体、潮流消费目前也没有场地专属证据。

该主题容易被商业品牌和视觉包装主导，当前排除。

### 4. `selected_theme`

最终选择主题A与主题B合并，主题C提供解释方法：

> **从县政大院到城市共同体：一座县政府原址中的工作、生活与城市变迁。**

建议形成五个叙事层次：

1. **县与城：** 长沙县、长沙市及行政区划背景。
2. **如何工作：** 县委、民政、宣教、农水、档案等机构及公共事务。
3. **如何共同生活：** 礼堂、活动中心、宿舍和庭院中的集体关系。
4. **如何成为家园：** 房改、私人产权和今天的居民生活。
5. **如何继续存在：** 保护、修缮、公共开放和居民共建的当代选择。

这五层可以分别落到建筑、路径、庭院、档案和运营活动，不依赖虚构人物或装饰性符号。

### 5. 对不同人群的意义

| 对象 | 主题需要回答的问题 | 可执行场景 |
|---|---|---|
| 场地居民 | 我的生活是否被尊重并记录 | 自愿口述史、居民展览、庭院共治 |
| 周边家庭 | 这里与普通老建筑有什么不同 | 建筑任务卡、家庭导览、城市地图 |
| 学校机构 | 可以从现场学习什么 | 县市沿革、公共事务、建筑修缮课程 |
| 历史见证者 | 个人资料如何成为可靠公共记忆 | 档案征集、照片辨识、证言核验 |
| 城市访问者 | 为什么需要专程到原址 | 建筑关系、礼堂和生活连续性导览 |
| 商业合作方 | 可以联动什么独特内容 | 专题展、票根导览、原址故事活动 |

### 6. `use_constraints`

- 所有建筑年代、功能、人物和事件必须保留档案出处，不得通过文学化叙述补齐空白。
- “1950年代建筑”和“1950–1996使用阶段”在正式档案确认前只能标为项目材料陈述。
- 红色历史必须区分沈家大屋、潘家坪片区与县政府原址，不得合并地点。
- 居民照片、姓名、家庭经历、产权及居住信息必须取得授权，并允许撤回。
- 不得用居民日常生活作为游客观赏内容。
- 档案、照片、报刊、影像和设计图纸须核验版权与复制许可。
- 修缮展示不得妨碍施工安全、消防和居民通行。
- 数字技术只能帮助呈现证据，不能制造无依据的历史场景。
- 非遗内容必须落实到具体项目、传承人、场地关系和合作协议后才能进入。
- 商业品牌不能获得建筑命名、历史解释或公共空间规则的主导权。
- 主题活动应以日间及低噪声为主；夜间适配度由下一项专项判断。

### 7. 仍需建立的证据包

在定位确定前，应取得：

- 正式不可移动文物和历史建筑名录、保护范围及认定说明。
- 每栋建筑的建成年代、设计、原始功能和历次改造记录。
- 长沙县政府迁入、使用和迁出该场地的正式时间线。
- 县委、民政、宣教、农水、档案等机构历史资料。
- 礼堂会议、演出和集体活动记录。
- 房改文件及住宅产权形成过程的非个人化说明。
- 居民、原工作人员和家属的自愿口述史。
- 沈家大屋准确位置及其与项目的线路关系。
- 可公开使用的照片、地图、报刊、文件和实物清单。

如果这些材料无法取得，主主题应收缩为“近现代建筑保护与社区共享”，不宣称完整县政史。

### 8. `handoff`

第7步定位可以承诺：

- 县政府原址的场所特定内容。
- 历史建筑保护与公众理解。
- 居民共生和社区公共文化。
- 小尺度原址教育、档案与城市记忆。
- 与周边文化节点形成条件性合作。

第7步不能承诺：

- 红色教育基地。
- 长沙县千年历史的完整展示窗口。
- 非遗产业集聚区。
- 数字媒体或文创产业园。
- 城市级客流目的地。
- 年轻潮流地标或深夜消费中心。
- 以全部历史建筑进行商业经营。

第6步质量门已通过。因前六步已经涉及傍晚活动和夜间使用，下一项先单独执行 `client-decision-nightlife` 的 `baseline`，通过后再进入第7步定位。

## `nightlife_assessment`：夜生活基础判断

### `mode_status`

- `baseline`：已完成。
- `product_check`：尚未执行；第8步形成具体产品、空间和时段后再逐项复核。
- 当前可以判断片区夜间空间基础，但不能确定营业时长、容量、客流、消费或收益。

### 核心结论

片区存在夜间照明和活动节点，但**没有形成可证明连续延伸到项目的商业娱乐高值带**。

当前主要夜光高值分别由：

1. 东北侧住宅、政府服务、停车和便民商业；
2. 南侧湘雅医院及医疗配套；

共同形成。华创、万达、富兴等商业娱乐节点的夜光处于范围中部，而非最高值区。

因此项目适合探索**日间为主、傍晚延伸、室内低噪声、预约可控**的文化活动；不支持把项目定位为酒吧、夜市、深夜演艺或夜生活目的地。

### 5. `access_constraints`

#### 片区尺度可以确认

- 范围内存在两个地铁站和多个商业、医疗、住宿节点。
- 开福寺路、芙蓉中路在路网模型中承担较强区域骨架作用。
- 华夏路、潘家坪路具有街坊分配作用。
- 片区存在夜间照明，但功能明显混合。

#### 项目周边尺度只能条件性判断

- 项目分析中心所在格不是高值格。
- 东北和南侧热点距分析中心约529米和830米起。
- 商场影院可形成活动来源，但没有连续夜光高值证明自然延伸。
- 正式项目边界和实际开放建筑尚未确定。

#### 入口尺度不能判断

当前缺少：

- 正式入口和居民入口坐标。
- 地铁出口至项目的实际步行线路。
- 路口、斑马线、信号灯及过街条件。
- 人行道连续性、照度、遮挡和夜间导视。
- 活动结束后的公共交通班次。
- 出入口安保和应急疏散方案。

因此不能说“入口照明充足”“夜间散场便利”或“地铁步行安全”。

### 6. 居民与保护约束

- 三栋住宅仍有居民正常居住，户数存在102与120两种口径。
- 庭院、礼堂和住宅空间相邻，声音和人群可能直接影响居民。
- 建筑存在墙体开裂、屋顶渗漏、管线老化、消防和无障碍缺失。
- 礼堂尚未完成结构、消防、声学和容量评估。
- 当前没有居民夜间噪声、投诉、休息时段和通行事件基线。
- 夜间景观照明必须服从历史风貌，不宜依靠强光和大面积亮化制造氛围。

这些条件决定项目即使开展夜间活动，也应从室内、低噪声、预约和可控制散场开始。

### 7. `baseline_judgment`

#### 解释A：连续商业娱乐夜生活基础

不成立。

反证是P90热点与华创、万达、富兴并不重合，项目中心也不在热点中；没有连续商场、影院、酒吧和夜间餐饮共同构成的空间证据。

#### 解释B：节点型夜间活动存在，但未自然延伸至项目

成立，是当前主判断。

商业影院、地铁、医院和居民社区分别形成不同夜间节点，但它们之间的功能、使用者和到达机制不同。项目必须通过预约活动和明确线路主动连接，不能等待自然溢出。

#### 解释C：高值主要由非休闲照明形成

部分成立。

两个主要高值组分别由社区行政、停车及医院医疗服务主导。它们能够证明夜间运行，不足以证明夜间休闲消费。

#### 解释D：片区整体夜间基础较弱

无法成立。

范围内存在较高辐亮度、商场、影院、地铁及医疗运行，但没有范围外对照，不能判断全市强弱。

**当前综合判断：**

> 片区具备节点型、混合功能的夜间活动基础；项目自身及附近商业娱乐节点未形成连续高值消费带。夜间定位应以傍晚文化延伸和预约活动为主，不承担深夜娱乐目的地角色。

### 8. 反证与改判条件

以下证据可能把判断上调为“可稳定开展晚间文化活动”：

- 现场确认华创、富兴或地铁方向存在连续、安全、照明充分的步行线路。
- 联动活动能够持续产生真实到场和复访。
- 商场、影院和周边餐饮的真实营业时段与项目活动衔接。
- 居民协商形成明确、稳定的结束时间和噪声边界。
- 礼堂及相关建筑通过结构、消防和声学审查。
- 晚间试运营没有持续投诉、散场或安全事件。

以下证据会使项目退回日间运营：

- 项目周边存在连续暗点、危险过街或散场交通中断。
- 居民投诉或通行冲突无法通过排期解决。
- 夜间活动主要依赖免费动员，没有复访或交易。
- 商场影院合作只有宣传，没有实际到场。
- 消防、安保或保护要求无法支持晚间开放。

### 10. `validation_plan`

在确定夜间产品前，应开展一次完整的现场夜间基线调查。

**空间调查**

- 标定正式入口、居民入口、活动出口和应急出口。
- 分别步行核查开福寺站、华创、富兴和潘家坪路方向。
- 记录路面、过街、人行道、遮挡、导视和连续暗点。
- 在入口、庭院、住宅边界、礼堂出口和主要路口记录照度。
- 核查商户实际营业状态，不能依赖POI名称。

**行为调查**

- 区分普通工作日、周末和真实活动日。
- 记录到达来源、方式、时间、同行关系和离场方向。
- 记录商场或影院联动代码，而非只统计总人数。
- 记录取消、提前离场和拒绝夜间到访的原因。

**运营与居民记录**

- 建立居民噪声、通行和投诉基线。
- 记录活动开始、结束、清场和最后工作人员离场。
- 记录安保、消防、照明、清洁和交通组织成本。
- 记录活动交易、退款及无消费参与。
- 任何事故、持续投诉或无法安全散场均作为停止信号。

首轮可覆盖普通工作日、周末和一次预约活动，但不预设营业结束时间。先取得基线，再由业主、运营方、街道和居民代表审批时段。

### 11. 城市政策边界

商务部转载长沙市商务局的[《培育夜间消费品牌 激发消费新潜能》](https://scyxs.mofcom.gov.cn/qkjl/art/2023/art_26f1904b066b4ad880000d4582a254a4.html)说明长沙支持夜游、演出、夜间公共文化、延时公交和消费场景。

该文件说明城市层面的政策环境，不证明本项目属于长沙夜经济重点区域，也不替代本项目的居民、安全、交通和营业验证。

### 12. `handoff`

第7步定位必须遵守：

- 不使用“夜生活目的地”“夜经济地标”等表述。
- 可以承诺日间公共文化，并条件性探索傍晚延伸。
- 夜间价值来自原址内容，不来自酒吧、夜市或泛娱乐。
- 项目应与商场影院进行点对点活动合作，不假设自然客流。
- 居民、消防、保护和最后一段到达先于营业时间。
- 第8步提出任何夜间产品后，必须再执行`product_check`。

## 第7步：项目定位

### 定位选择

当前建议将项目定位为：

> **居民共生型县政原址公共文化院落。**  
> 面向原址居民、周边社区和学校，以长沙县政府原址建筑群、礼堂、档案与大院生活为证据，通过保护修缮、原址展陈、社区共建和预约教育，把封闭或闲置大院转化为片区级公共文化节点；条件成熟后，再成为城市文化线路中的专题微目的地。

项目当前级别是“片区级公共文化节点”，不是城市级文旅地标、商业综合体、产业园或夜生活目的地。

### 候选比较

| 候选定位 | 成立基础 | 主要问题 | 当前判断 |
|---|---|---|---|
| 居民共生型县政原址公共文化院落 | 原址建筑、礼堂、大院生活、居民和社区关系具有不可替代性；符合保护与公共文化任务 | 需要解决安全、产权、居民规则和原址档案 | **主选** |
| 城市文化线路中的原址专题微目的地 | 可与开福寺、湖南博物院、片区历史资源形成线路关系 | 尚无真实外来预约、联票、线路合作和项目客流证据 | **条件性升级方向** |
| 历史建筑创意生活街区 | 周边已有华创、富兴、影院、餐饮和住宿，可产生商业联动设想 | 普通商业供给重复；居民、保护、消防和开放条件不支持全域经营 | **排除** |
| 社区历史建筑共享场所 | 即使县政史证据不足，建筑和社区日常使用仍有价值 | 城市文化辨识度和外来访问理由较弱 | **降级定位** |

### 为什么选择这一定位

第一，项目首先承担的是保护、安全和居民共生任务。现有材料中的13栋建筑、约2万平方米以及8栋保护建筑约13,071.78平方米仍有待正式测绘和名录核验；墙体、屋顶、管线、消防和无障碍问题也意味着项目暂不具备“大规模开放经营”的前提。

第二，真正稀缺的不是餐饮、影院、住宿或一般文化活动。15分钟范围内已有681条餐饮、585条购物、151条住宿以及万达影城、保利国际影院、华创国际广场、富兴时代等具名设施。项目可以与这些设施协同，但不应复制它们。

第三，项目最独特的资源是“原址关系”：县政府建筑、办公制度、礼堂、宿舍、庭院、居民和城市变迁发生在同一空间中。这个关系无法由普通商场、文化馆或综合博物馆替代。

第四，市场机制暂时只支持片区级定位。周边约5.81万人的面积加权人口可以说明社区服务背景，但不能换算项目客流；湖南博物院和开福区景区游客量也不能自动转化为项目到访。当前更可靠的是居民复访、学校和机构预约，城市游客只能作为后续验证对象。

第五，夜间条件不足以改变项目级别。项目中心夜光约处于数据集第28百分位，华创、万达和富兴附近约为中位水平；主要高值区分别对应住宅、政府、停车设施和湘雅医院，而不是连续的商业娱乐带。因此可以测试傍晚预约活动，但不能把项目定位成夜间消费目的地。

### 价值承诺

对居民：改善安全和公共环境，同时保留生活权利、记忆与参与权，不把居民当作需要被清退的“场地障碍”。

对周边社区和学校：提供可重复使用的地方历史课堂、社区活动与建筑修缮教育，而不是一次性参观。

对城市访问者：提供能够在原址阅读县政制度、大院生活与城市变迁的专题内容，但不承担长沙县完整通史展示。

对政府和业主：用分阶段开放降低一次性改造和运营风险，使保护修缮、居民协商、内容建设和市场验证同步推进。

### 明确不做

- 不做红色教育基地，除非取得发生于项目本体的正式史料。
- 不承担长沙县全部历史展示。
- 不与湖南博物院竞争综合博物馆角色。
- 不做普通文创产业园或商业街区。
- 不做酒吧、夜市、大型露天演出和深夜娱乐。
- 不默认整体搬迁、全部建筑开放或全部经营化。
- 不用周边人口、城市游客量或约2万平方米建筑规模预测项目收入。
- 不把历史建筑本身当作商业成功的充分条件。

### 阶段目标

**阶段0：资格闭合**

完成保护名录、建筑测绘、产权与居民口径、安全消防、可开放建筑清单和原址档案核验。当前102户与120户的居民口径冲突必须在本阶段解决。

**阶段1：最小开放原型**

形成一条安全开放路径、一组原址内容、一套居民使用规则和若干预约活动原型。先记录报名、到场、停留、复访、居民反馈和取消原因，不预设客流阈值。

**阶段2：机制验证**

验证社区是否持续复访、学校和机构是否履约、原工作人员及居民是否愿意参与内容生产，以及外部访问是否具有独立预约动机。

**阶段3：条件升级**

只有在稳定外来预约、跨节点合作和可持续运营能力形成后，才升级为“城市文化线路中的专题微目的地”。

### 改判条件

继续当前定位：安全开放条件成立，居民规则可执行，原址档案能够支撑内容，社区或机构使用持续发生。

升级定位：城市访问者形成可核验的独立预约、复访和合作来源，而不是依赖周边景点客流推算。

降级定位：县政原址证据不足、居民不愿参与或外部访问机制长期不成立，转为“社区历史建筑共享场所”。

暂停开放：结构、消防、产权或保护审批无法支持公共使用。

### 对第8步的约束

下一步产品组合必须同时兑现五件事：原址证据、居民日常价值、机构预约课程、条件性城市访问以及低噪声、日间优先、傍晚可控。任何夜间展览、演出、餐饮或导览产品，进入空间和运营设计前都必须通过夜生活 `product_check`。

## 第8步：产品组合

### 产品原则

产品不围绕“把两万平方米填满”，而围绕四项已经成立的任务组织：

1. 保存并解释县政府原址证据。
2. 为居民和周边社区提供持续价值。
3. 建立学校、文化机构可预约的使用机制。
4. 小规模验证城市文化访问需求。

消费产品只能承担服务补充和成本回收，不能反过来支配保护、居民与公共文化目标。

### 两套组合比较

| 组合 | 构成 | 优点 | 风险 | 判断 |
|---|---|---|---|---|
| 最小可运行组合 | 原址展陈、预约导览、机构课程、口述史共建、社区共享、基础接待 | 对开放面积和商业客流依赖较小；可以逐项验证 | 前期收入能力有限，需要明确公共投入与履约责任 | **一期采用** |
| 扩展组合 | 轮换展览、城市文化线路、衍生品、傍晚活动、条件性轻餐 | 增加外来访问理由和消费承接 | 容易提前商业化；依赖安全开放、真实客流和合作机构 | **达到阶段门后增加** |
| 商业主导组合 | 餐饮街区、酒吧、夜市、住宿、演艺聚集 | 理论上收入项目较多 | 与周边重复，且居民、消防、保护和夜间空间证据均不支持 | **排除** |

### 一期最小组合

| 产品 | 解决的任务 | 主要对象 | 空间与运营条件 | 必须记录 |
|---|---|---|---|---|
| 原址证据展陈 | 证明项目为何不可替代 | 社区、学校、城市访问者 | 选择安全开放建筑；展项必须对应建筑、档案或口述史 | 到访来源、停留、内容理解、缺失史料 |
| 原址预约导览 | 把建筑、礼堂、宿舍、庭院串成叙事 | 学校、机构、小规模城市访问者 | 使用经批准的最小安全路线；未开放建筑只作外部解释 | 预约、到场、取消、进出时间、拥堵点 |
| 县政与城市变迁课程 | 建立稳定机构使用机制 | 学校、文化站、社会组织 | 需要课程负责人和可教学空间；内容不得泛化为长沙县通史 | 机构来源、履约率、参与反馈、再次预约 |
| 大院口述史与档案共建 | 形成原址独有内容 | 居民、原工作人员、历史见证者 | 建立知情同意、使用授权、隐私和撤回机制 | 访谈授权、资料来源、争议和修订记录 |
| 社区共享计划 | 让保护更新对居民产生日常价值 | 原址居民、周边社区 | 居民流线与访客流线分开；活动规则共同制定 | 使用频次、居民参与、投诉、冲突和取消原因 |
| 基础接待与休息 | 支撑上述产品正常发生 | 全部使用者 | 预约核验、卫生间、无障碍、饮水、应急和寄存条件先核查 | 服务使用、拒绝原因、无障碍问题和安全事件 |

共同工作流是：

> 预约或社区报名 → 接待与规则说明 → 原址展陈 → 经批准的院落导览 → 课程或社区活动 → 反馈与复访记录。

它要求访客活动不能穿越居民私密区域，也不能把未完成安全评估的建筑临时纳入路线。

### 条件性扩展产品

**轮换专题展览**

只有在原址档案和口述史形成稳定内容生产机制后增加。主题仍须服务“县政工作、大院生活与城市变迁”，不能变成与项目无关的通用艺术展场。

**城市文化线路联动**

可以与开福寺、片区历史资源及湖南博物院周边访问形成线路测试，但必须以真实预约来源和合作记录证明，而不能用周边游客量推算项目客流。

**小规模衍生品**

优先采用档案出版物、导览手册、口述史成果和建筑研究材料。先测试预订或小批量销售，不先建设大面积文创商店。

**条件性轻餐或茶歇**

只作为课程、社区活动和预约访问的配套。食品安全、排烟、垃圾、配送、居民影响和真实购买记录成立后再决定是否固定经营，不发展成普通餐饮街区。

### 具名协同对象

- **湘雅路街道综合文化站、开福区文化馆、开福区24小时自助图书馆**：共同开发课程、社区活动和报名渠道；合作意愿与职责尚需正式确认。
- **湖南博物院**：可探索研究方法、公共教育或线路信息协同，但不得假定其导流或品牌授权。
- **华创国际广场、富兴时代、万达影城**：只用于交叉发布、联合预约或傍晚活动测试，不视为自动客源。
- **原址居民和原工作人员**：是内容共同生产者和规则参与者，不是布景、表演者或普通供应商。
- **保护、档案、消防及属地管理部门**：负责确认史料、开放边界和安全条件，不由运营团队自行替代审批。

### 夜间产品复核

2025年夜光高值主要对应东北侧住宅、政府和停车设施，以及南侧湘雅医院相关设施；项目中心约处于范围内第28百分位，商业娱乐节点的亮度约在中位附近。现有证据支持“节点型夜间活动”，不支持“连续夜间消费带”。

| 夜间候选 | 决定 | 条件 |
|---|---|---|
| 傍晚预约导览 | `test` | 仅走批准路线；先核查照明、过街、导视和散场；按预约控制 |
| 室内低噪声展览、讲座 | `conditional` | 消防、容量、隔声、居民规则和闭馆责任明确 |
| 活动配套茶歇 | `conditional` | 不独立引流；解决食品、垃圾、配送和居民影响 |
| 室内小型演出 | 暂不纳入 | 缺少声学、消防、容量和散场证据 |
| 酒吧、夜市、深夜餐饮 | `exclude` | 夜光热点功能不支持，且与居民和保护约束冲突 |
| 住宿产品 | `exclude` | 周边已有大量住宿供给，项目也缺少夜间管理资格 |

不预设固定营业时长。傍晚测试的结束时间应由现场照明、公共交通、实际散场、居民意见和投诉记录共同校准。

### 下一步空间要求

第9步必须为以下功能寻找明确承载位置：最小安全开放路线、原址展陈、课程空间、社区共享空间、接待服务、居民私密边界和后勤路径。人数上限须由结构、消防、疏散和无障碍核查确定，不能先按建筑面积估算。夜间候选必须集中在容易管理、隔声和快速疏散的室内空间，不得侵入居民生活区。

## 第9步：空间布局

### 判断尺度

当前项目包有15分钟等时圈、分析中心和区域道路几何，但没有正式项目红线、建筑轮廓、院门位置、产权边界及内部道路。

因此，本步能够确定：

- 外部道路的功能层级。
- 产品之间应有的空间关系。
- 访客、居民、后勤和应急流线的分离原则。
- 选择入口和开放建筑的判定条件。

目前不能确定“哪栋楼做展厅”“哪个院门是主入口”或具体容纳人数。

### 外部道路结构

分析中心约为 WGS84 `[112.980771, 28.224172]`，最近的具名道路是潘家坪路，向东连接芙蓉中路；开福寺路位于北侧。

| 道路 | 模型表现 | 通俗含义 | 空间动作 |
|---|---|---|---|
| 芙蓉中路 | 附近路段整合度约0.91，选择度约0.54–0.93 | 在当前路网模型中既容易与其他道路连接，也较可能承担跨区域通过路径；不是实测人流 | 承担城市级识别和导向；重点核查过街，不直接默认设置落客或车行入口 |
| 潘家坪路 | 附近路段整合度约0.79–0.84，选择度约0.26–0.47 | 更接近街坊分配道路，能够把芙蓉中路的到达转换到项目界面 | 作为主要到达界面的优先核查方向，设置减速、步行识别和预约集散 |
| 开福寺路 | 路段整合度约0.97，选择度约0.42 | 在模型中具有较强东西向连接性，可承担北侧文化节点和轨道到达的转换 | 形成外围导视和步行线路，但不能在未核查连续人行道前宣称已连通 |

这些指标描述道路拓扑关系，不等于真实车流、步行量或入口安全。入口资格仍须通过红线、现场道路、过街和产权核查。

### 布局方案比较

**方案A：单入口、集中开放**

访客从一个受控入口进入，在一栋核心建筑和相邻院落完成展览、导览与课程。

优点是开放面积小、安保和消防管理相对集中，适合最初试运行。问题是居民、访客、配送和应急可能共用狭窄界面，活动增加后容易冲突。

**方案B：公共脊柱与居民静区分离**

以一个公共到达界面连接接待、展陈、院落和课程空间；居民保留独立生活通路，后勤从低冲突界面进入。

该方案最符合“居民共生型公共文化院落”，但依赖正式红线、院门和消防条件证明存在可分离通路。

**方案C：多院落全面开放**

多个院落和建筑同时布置展览、商业和活动。

它虽然能提高空间使用量，但会扩大消防、安保、居民扰动和修缮投入，目前排除。

### 选择的空间结构

采用“**集中开放起步，逐步形成公共脊柱与居民静区**”的结构。

1. **城市导向层**  
   在芙蓉中路、潘家坪路及北侧到达方向建立分级导视，把区域交通转换为步行到达。导视只能指向已确认入口。

2. **到达与控制层**  
   在最安全、无障碍条件最好、对居民影响最小的临街界面设置预约核验、等候、问询和应急说明。潘家坪路方向是优先核查假设，不是已确定入口。

3. **核心体验层**  
   首期只选择一栋通过结构、保护和消防核验的建筑承载原址展陈，并连接一段最小院落导览路线。内容顺序应由建筑和档案证据决定。

4. **弹性活动层**  
   课程、口述史和社区活动共用可转换空间，通过预约和时段安排切换，不为每类活动提前建设独立场馆。

5. **居民静区**  
   住宅入口、晾晒、停车、日常交往和私密空间不进入默认参观路线。公共活动与住宅之间设置视觉、声学和时间缓冲。

6. **后勤与设备层**  
   展陈维护、垃圾、配送、设备和工作人员进入应避开访客集散与居民主要通路。当前缺少院内几何，具体界面待测绘确定。

7. **应急层**  
   所有开放空间必须能够回到经消防批准的疏散出口和集结点。历史院落的观赏连续性不能替代消防连续性。

### 使用者流线

**访客**

外围导视 → 预约核验 → 原址展陈 → 批准的院落路线 → 课程或休息 → 反馈 → 原入口或批准出口离开。

主要冲突是等候外溢、过街、误入住宅区和活动结束后的集中离场。

**居民**

城市道路 → 居住入口 → 住宅与日常院落。居民无需穿越售检票或活动区，也不应因公共开放改变基本通行权。

**学校与合作机构**

预约确认 → 团体集散 → 安全说明 → 课程空间 → 分组导览 → 统一清点离开。团体到达不得占用居民入口或机动车道。

**员工**

值班进入 → 开放前巡检 → 接待或教学 → 闭馆清场 → 设施与事件记录。必须有明确的首开和末关责任人。

**后勤**

预约配送 → 指定卸货点 → 短路径进入储藏或设备空间 → 垃圾和包装原路退出。配送时间与团体到达、居民高频通行错开。

**应急**

报警 → 停止活动 → 分区疏散 → 集结清点 → 消防救援进入。居民与访客疏散方案必须同时成立。

### 日夜切换

日间可以运行完整的展陈、导览、课程和社区共享组合。

傍晚预约导览只开放照明连续、边界清楚、可以快速退出的最小路线；室内低噪声讲座只能放在远离住宅、隔声和消防合格的空间。夜间不开放新增院落、不经过居民静区，也不为酒吧、夜市或露天演出预留场地。

具体结束时间必须根据公共交通、实际散场、现场照明、居民反馈和投诉记录校准，不能由夜光值直接确定。

### 容量边界

当前没有建筑面积分栋表、结构荷载、疏散宽度、出口数量、消防分区、卫生间和无障碍数据，不能给出人数。

每个空间的运行上限应取以下结果中的最小值：

> 结构允许人数、消防核定人数、疏散能力、卫生与无障碍承载、运营看护能力、居民共同规则允许强度。

预约系统必须按批准上限锁定名额，不能依靠现场人员临时判断。

### 必须完成的设计动作

- 测绘红线、建筑、院门、台阶、坡度、内部道路和居民通路。
- 核查潘家坪路侧步行界面、停车、落客和与芙蓉中路交叉口的过街条件。
- 建立城市道路、项目入口、院内节点三级导视。
- 补齐无障碍连续路线，而不是只在入口增加坡道。
- 绘制居民私密边界、访客禁入区和配送禁行时段。
- 对傍晚路线逐点检查照明、眩光、暗点、监控盲区和紧急退出。
- 对活动空间进行声学测试，并记录住宅侧实际噪声和投诉。
- 将保护构件、修缮施工区和不可进入建筑纳入实体隔离。

### 交给第10步的运营责任

运营体系必须明确入口值班、预约审核、导览、课程、居民协调、档案授权、消防巡检、夜间闭场、配送管理和事件记录的责任主体。没有责任人的空间不得开放；无法持续值守的入口和院落不得进入一期范围。

## 第10步：运营模式

### 当前判断

建议采用：

> **业主保留资产、保护与公共任务主责，专业现场团队负责日常运营，居民参与规则共治，内容和商业伙伴按项目接入的联合运营模式。**

项目材料只是提出“长房业主基础改造后招商运营，还是自投自营”的问题，并未提供已批准的运营合同或授权关系。因此，以下“业主”均指最终经法律文件确认的资产或实施责任主体，不能直接视为已经确定由某家公司运营。

### 模式比较

| 模式 | 优点 | 主要风险 | 判断 |
|---|---|---|---|
| 业主完全自营 | 保护、公共任务和资产决策一致 | 是否具备策展、社区、教育和现场运营能力尚无证据 | 可作为过渡，不宜未经能力核查直接采用 |
| 整体委托商业运营 | 招商、活动和消费运营较灵活 | 容易把公共任务转成客流和租金目标，居民与保护约束可能被弱化 | 不采用全权委托 |
| 政府部门直接管理 | 公共属性和审批接口清楚 | 日常活动、合作和数据复盘可能不够灵活 | 可承担监督，不建议包办现场运营 |
| 联合运营 | 业主保留不可转移责任，专业团队执行，居民和内容伙伴拥有明确接口 | 合同和协调机制相对复杂 | **当前主选** |

### 责任结构

| 事项 | 最终负责 | 日常执行 | 必须协同 | 监督或确认 |
|---|---|---|---|---|
| 保护修缮与资产安全 | 业主/实施主体 | 专业工程与设施团队 | 文保、设计、居民 | 主管部门 |
| 年度公共服务计划 | 业主 | 现场运营团队 | 街道、文化机构、居民 | 公共部门 |
| 开放与预约 | 现场运营负责人 | 接待、导览、课程人员 | 安保、设施、居民联络 | 业主 |
| 原址内容与档案 | 内容负责人 | 策展、档案、口述史团队 | 居民、原工作人员、研究机构 | 业主及相关权利人 |
| 居民边界与共建规则 | 业主与居民协商机制 | 社区联络岗位 | 现场运营、物业 | 街道或属地单位 |
| 消防、疏散和闭场 | 现场安全负责人 | 值班、安保、设施岗位 | 活动负责人、居民联络 | 业主及主管部门 |
| 商业与活动合作 | 业主审批 | 运营团队执行 | 内容、安全、居民联络 | 财务与合规 |
| 数据与复盘 | 业主拥有项目经营数据 | 运营团队采集维护 | 合作机构 | 审计或监督主体 |
| 投诉和重大事件 | 业主承担最终问责 | 现场负责人先行处置 | 居民、安保、相关伙伴 | 属地及主管部门 |

“居民参与维护”来自项目愿景，但不能被理解为居民无偿承担保洁、安保或经营责任。居民参与的是规则制定、日常观察、内容共建和反馈，专业责任仍由合同主体承担。

### 核心运行流程

**开放前**

设施巡检 → 消防和疏散检查 → 居民通路确认 → 当日预约与人员配置核对 → 开放负责人签字。任一关键项不通过，相关空间不开放。

**普通参观**

预约或现场登记 → 接待核验 → 安全与边界说明 → 展陈或导览 → 离场清点 → 反馈记录。未预约团体不得挤占居民通路或临时扩大开放区域。

**机构课程**

机构申请 → 内容和安全审核 → 场地排期 → 责任人确认 → 到场清点 → 课程执行 → 离场与履约记录 → 是否复约。合作机构负责组织纪律，项目方仍承担场地安全责任。

**档案与口述史**

资料提交 → 来源登记 → 权利和隐私确认 → 内容核验 → 明确展陈、研究或传播权限 → 使用记录 → 异议、更正或撤回。未经授权的居民信息不得进入公开展览或宣传。

**社区活动**

居民或社区提出需求 → 核查空间、噪声和公共任务 → 排期 → 执行 → 记录参与、冲突和反馈。社区使用不能被商业活动长期挤出。

**维护与修缮**

发现问题 → 隔离危险区域 → 设施负责人判断 → 区分日常维修、保护修缮和紧急工程 → 业主批准 → 专业实施 → 验收后重新开放。运营人员不得自行改变保护构件。

**投诉与事件**

现场接收 → 判断是否立即停用 → 记录时间、位置、活动和责任人 → 通知居民联络或安全负责人 → 处理与回访 → 周期复盘。结构、消防和人身安全事件直接升级，不等待一般投诉流程。

### 公共义务与收入边界

**应由业主或公共资金首先保障**

- 保护修缮和结构安全。
- 消防、无障碍、基础管线和居民必要通行。
- 原址基本展陈和最低公共开放。
- 社区服务、档案保管和安全管理。
- 未经营建筑的基本维护。

这些成本不能假定由门票、餐饮或文创收入覆盖。

**可以测试的经营性收入**

- 专题导览或定制课程。
- 符合公共属性的场地使用。
- 原址出版物和小批量衍生品。
- 活动配套茶歇。
- 经批准的联合文化项目。

目前没有票价、订单、交易、客流或合同证据，这些只能进入试运营验证，不能写成已经成立的收入来源。

**可能的外部资金**

政府购买公共文化服务、专项保护资金、业主投入、机构合作经费、公益赞助等均需正式政策、合同或预算证明。不能在财务模型中把尚未申请或批准的资金作为确定收入。

公共服务与经营业务应分别核算。商业收入可以补充活动和运营成本，但不得以减少居民权利、基本开放或保护投入为代价。

### 合作准入

所有合作方必须写入：

- 服务对象、活动内容和可使用空间。
- 内容真实性及知识产权责任。
- 安全、人员、设备和保险责任。
- 收费、结算、退款和成本承担。
- 预约、到场、交易和投诉数据的提交格式。
- 居民边界、噪声和结束时间。
- 违规暂停、整改、退出和替换机制。

华创、富兴、万达影城等周边商业设施只适合做联合发布或预约测试，不获得项目内容和空间的主导权。文化馆、文化站、学校及研究机构的合作也需按真实履约记录续约，不因其公共身份自动长期占用空间。

### 夜间运营

夜间只保留傍晚预约导览和室内低噪声活动两个候选，不设置常态深夜班次。

活动前必须完成路线照明、过街、天气、疏散、居民边界和公共交通核查；活动中由一名明确的现场负责人拥有停止权；结束后执行访客清点、居民区域检查、设备断电、门禁复位和事件登记。

出现以下情况应立即停止相应夜间产品：

- 照明或疏散设施异常。
- 访客误入居民区域。
- 实际散场无法被当班人员管理。
- 连续出现与同类活动相关的居民投诉。
- 活动噪声或设备使用超出批准条件。
- 交通条件变化导致预约方案失效。

具体结束时间和投诉阈值应先建立试运行基线，再由业主、运营和居民协商机制批准。

### 当前能力缺口

项目尚需取得或配置：

- 保护建筑设施管理能力。
- 原址策展、档案和口述史管理能力。
- 社区与居民协调岗位。
- 公共教育和机构合作能力。
- 预约、数据和隐私管理能力。
- 消防、安全与事件处置能力。
- 傍晚照明、散场和闭场管理能力。
- 合同、采购、成本核算和绩效复盘能力。

### 交给第11步的财务变量

财务校验必须分别记录保护修缮、基础开放、公共服务、日常运营和经营性活动成本。业务量至少按产品、来源、时段和付费状态拆分，并同步记录人员工时、开放建筑、能源、维护、退款、投诉、合作分成和实际交易。

在这些基线形成前，第11步只能建立成本责任、资金结构和盈亏敏感项，不能输出伪精确的客流、收入或回收期。

## 第11步：财务校验

### 当前结论

项目当前不能计算可信的投资回报率、回收期或年度收入。

已经能够作出的财务判断是：

> 项目的保护修缮、安全开放和居民共生属于前置成本，不能依靠尚未验证的门票、餐饮或文创收入倒推投资；一期应先确定“最小安全开放单元”的真实成本和公共资金缺口，再用试运营数据决定是否增加建筑、产品和经营投入。

首先限制项目的不是15分钟范围内的人口或商业供给，而是分栋修缮成本、安全开放资格、资金责任和运营能力。

### 财务驱动模型

**总投资**

```text
总投资 =
前期调查与审批
+ 结构加固和应急排险
+ 保护修缮
+ 水电、排污、消防和无障碍
+ 最小展陈与活动适配
+ 室外道路、照明和居民边界
+ 设计、监理与专业服务
+ 经批准的预备费用
```

必须按建筑分别计算，不能用约20,000㎡乘一个统一“行业单方造价”。礼堂、档案楼、办公建筑、住宅和简易仓库的保护要求与工程内容不同。

**年度固定运营成本**

```text
固定运营成本 =
核心人员
+ 安保与消防值守
+ 设施维护
+ 能源与保洁
+ 内容和档案维护
+ 保险、系统和行政
+ 居民协调
+ 最低公共服务活动
```

**产品净收入**

```text
单项产品净收入 =
实际完成数量 × 实收单价
- 退款
- 合作方分成
- 材料、讲师、支付和增量人员成本
```

预约人数不能替代实际到场，活动场次不能替代完成履约，销售额也不能替代项目可留存收入。

**年度资金缺口**

```text
资金缺口 =
固定运营成本
+ 公共服务履约成本
+ 当年维护与修缮
+ 融资成本
- 已批准公共资金
- 业主投入
- 实际经营净收入
- 已签约合作资金
```

未批复的补贴、赞助和合作意向不能计入资金来源。

### 情景校验

**保守情景：保护与最小开放**

只修缮一处核心展陈空间、最短安全路线和必要公共设施，不计经营收入。

```text
所需资金 =
最小开放投资
+ 基础运营成本
- 已批准的业主或公共资金
```

当前可以确定的是：外部资金或业主预算必须覆盖安全、保护和基本运营。如果资金不足，应缩小开放范围或延后开放，不能削减消防、结构和居民保障。

**基准情景：最小产品组合运行**

运行原址展陈、预约导览、机构课程、口述史和社区活动，仅计入真实完成的公共采购与经营收入。

```text
年度净缺口 =
基础运营成本
+ 产品增量成本
- 已签约公共服务收入
- 实际产品净收入
```

这个情景的目标不是预设盈亏平衡，而是取得单位活动成本、每开放日成本、机构履约成本、实际支付和复访数据。项目是否需要长期公共补贴，应由这些记录确定。

**扩展情景：增加建筑和城市访问产品**

只有当新增建筑取得开放资格、现有产品产生稳定使用、运营团队仍有能力且增量资金已经落实时启动。

```text
增量财务结果 =
新增产品净收入
+ 新增确定性合作资金
- 新增人员、维护、能源和内容成本
- 新增修缮与资金成本
```

经营收入不能覆盖全部增量成本时，只有公共服务价值经过批准，扩展才可以继续。

**压力情景：修缮超预期、开放延迟、使用不足**

```text
压力资金缺口 =
基础资金缺口
+ 新增病害和工程变更
+ 延期管理及维护成本
+ 低于计划的实际净收入
```

若结构或消防导致核心建筑不能开放、保护工程没有独立资金、居民协商无法闭合，或运营资金只依赖未签约商业收入，应暂停扩建和招商。

### 首要约束

1. **分栋安全资格**：决定哪些资产能产生公共服务或经营活动。
2. **保护修缮工程量**：可能比室内业态设计更早决定投资规模。
3. **消防和基础设施**：决定容量与开放时间，不能后补。
4. **居民产权和运行边界**：决定施工组织、入口和持续运营成本。
5. **资金授权**：公共任务、资产维护和经营投入必须分别落实责任。
6. **真实业务量**：没有完成订单和复访，不能扩大产品或人员。
7. **运营能力**：开放建筑越多，安保、维护和内容成本越高，不等于收入同步增长。

### 资金责任建议

**业主或公共资金承担**

保护修缮、结构安全、消防、无障碍、基础管线、居民必要环境、基本展陈和最低公共服务。

**运营预算承担**

现场团队、日常维护、保洁安保、预约系统、内容更新、社区协调和数据复盘。

**产品收入承担**

课程材料、讲师、活动增量人员、衍生品生产、茶歇以及合作分成。产品至少应核算自身增量成本，但是否承担固定成本需由公共任务性质决定。

**合作方承担**

其专属设备、人员、保险、材料和超出公共配置的增量投入。所有投入应可识别、可退出，并符合保护审批。

不建议在收入机制尚未验证时，以高成本债务或长期商业租约覆盖保护修缮。

### 最小询价包

进入投资决策前至少取得：

- 建筑、产权和使用状态分栋表。
- 保护身份和允许改造清单。
- 结构、屋面、墙体、木构及潮湿病害报告。
- 水电、排污、消防、无障碍和室外工程量。
- 展陈与活动空间的最低配置规格。
- 分栋工程报价、税费、工期和不可预见项说明。
- 基础运营岗位、工时、能源、保险和维护报价。
- 居民通行、施工和公共空间相关成本。
- 已批准资金、付款节点及资金使用限制。

### 第12步阶段门

分期实施不能仅按“先改几栋、再改几栋”划分。每个阶段必须同时取得：

- 可开放建筑和路线的专业批准。
- 对应工程量、报价和资金来源。
- 业主与运营责任文件。
- 居民边界与协商记录。
- 实际运营和产品数据。
- 是否进入、缩减、暂停或退出的审批决定。

下一步将据此把项目拆成“证据与排险、最小开放、机制验证、条件扩展”四类阶段。

## 第12步：分期实施

### 分期原则

项目不按“第一年修几栋、第二年招商几栋”推进，而按证据成熟度推进：

> 先闭合权属、保护、安全和居民规则，再测试内容与使用机制；只建设已确认能够运行的最小单元，最后才决定是否扩展建筑、夜间活动和城市访问产品。

任何阶段都不能用下一阶段可能获得的收入，替代本阶段已经需要落实的安全和资金。

### 阶段0：前置核验与止损

**需要验证**

- 正式项目红线、13栋建筑及院门道路是否准确。
- 8栋保护建筑的法定身份、保护范围和允许干预方式。
- 三栋住宅究竟涉及102户还是120户，以及产权、抵押和实际居住情况。
- 每栋建筑的结构、屋面、墙体、木构、管线、消防和无障碍状态。
- 哪些建筑和道路必须立即封闭、排险或维护。
- 谁是资产、建设、审批和居民协调的正式责任主体。

**最小投入**

测绘、档案与名录核验、分栋安全检测、消防初判、产权调查、居民访谈和应急排险。不开展大面积装修、招商或收费活动。

**责任主体**

最终业主或实施主体牵头，文保、规划、消防、结构、产权、街道和居民代表共同参与。

**交付物**

- 红线与分栋档案。
- 保护和权属矩阵。
- 居民基线。
- 建筑安全分级。
- 禁入、排险和可继续研究清单。
- 初步工程量与资金责任表。

材料曾计划在2025年10月底前完成约102户的入户调查，但当前项目包仍写“待核实”，不能视为已经完成。

**阶段门**

只有红线、责任主体、保护身份、安全风险和居民基本口径闭合，才进入下一阶段。结构、产权或保护审批存在实质障碍时，暂停对应建筑，不要求全项目同步推进。

### 阶段1：低成本内容与机制试验

本阶段可以在已经合法安全的空间或场外合作场所进行，不以历史建筑开放为前提。

**需要验证**

- “县政工作、大院生活与城市变迁”是否有足够原址档案和口述史支撑。
- 居民是否愿意参与规则制定和内容共建。
- 学校、文化站和社会组织是否会形成真实预约与履约。
- 现场运营、档案授权、投诉和数据流程能否运行。
- 哪些内容真正需要回到原址呈现。

**最小投入**

档案整理、口述史采集、可移动展陈原型、场外课程、居民工作坊、预约和数据记录工具。

**交付物**

- 带来源和授权的内容底稿。
- 一套原址展陈原型。
- 一套机构课程原型。
- 居民共建和边界规则草案。
- 实际报名、到场、取消、反馈和复约记录。
- 运营岗位与流程测试记录。

**阶段门**

由业主、内容负责人、居民协商机制和运营负责人共同评审。若县政原址证据不足，主题降级为社区历史建筑共享；若机构履约或社区使用没有持续机制，缩小专用教学空间，不直接增加商业产品。

### 阶段2：最小安全开放单元

**建设范围**

只建设：

- 一处通过核验的核心展陈建筑。
- 从正式入口到核心建筑的最短安全路线。
- 必要的消防、无障碍、卫生、照明和接待设施。
- 一个可兼容课程、口述史和社区活动的弹性空间。
- 居民通路、公共开放与后勤之间的实体边界。

礼堂可以作为后续重点空间，但材料中的“形象标志和主要空间”只是愿景；未通过结构、消防、保护和运营核验前，不能自动纳入一期。

**运行内容**

日间原址展陈、预约导览、机构课程、口述史和社区共享。暂不运行酒吧、夜市、住宿、深夜餐饮或大型演出。

**交付物**

- 工程验收和开放许可。
- 经批准的容量与疏散方案。
- 业主、运营和居民运行协议。
- 日常开放和异常处置手册。
- 独立记录的建设投资、固定运营成本和产品成本。
- 完整试运营数据。

**阶段门**

至少完成一个能够覆盖计划中主要产品和时段的完整运营观察周期，再由责任主体依据基线批准阈值。没有直接证据时不预设客流、收入或复访比例。

### 阶段3：稳定运营与重点建设

**进入条件**

- 核心建筑持续安全运行。
- 居民通行和投诉机制可执行。
- 社区复访或机构预约形成持续记录。
- 运营团队能够完成开放、维护、内容和数据责任。
- 固定运营资金有明确来源。
- 下一栋建筑的保护方案、工程量和资金已经独立落实。

**可增加内容**

- 轮换专题展览。
- 更完整的原址导览。
- 经验证的机构课程。
- 小批量出版物和衍生品。
- 条件性城市文化线路合作。
- 经夜间复核通过的傍晚预约导览或室内低噪声活动。

每增加一栋建筑，都应作为独立投资和运行单元重新通过安全、内容、运营与资金门，不因总体规划已经批准而自动开放。

### 阶段4：条件性扩展

只有以下证据同时成立时，项目才从片区级公共文化节点升级为城市专题微目的地：

- 城市访问者产生独立、可追溯的预约和复访。
- 与文化机构或周边节点形成真实履约合作。
- 新增开放没有削弱居民权利和基本公共服务。
- 运营收入、公共资金和资产维护责任能够长期区分并落实。
- 扩展建筑具备独立安全和资金条件。
- 现场团队可以承受更长开放时间和更复杂流线。

扩展不等于全面商业化。普通商业街、酒吧、夜市、住宿和大型露天演出仍不进入默认方案。

### 依赖关系

```text
正式红线与责任主体
→ 保护、权属和居民核验
→ 分栋结构与消防检查
→ 可开放清单
→ 设计、审批、工程量和资金
→ 修缮与验收
→ 运营合同、岗位和保险
→ 最小开放
→ 使用、成本和投诉基线
→ 稳定运营
→ 条件性扩展
```

档案研究、居民协商、内容原型和合作测试可以并行推进，但不能越过安全开放和权属许可。

### 停止、调整与扩展

**立即停止**

- 结构、消防或人身安全不成立。
- 权属或保护审批禁止使用。
- 居民基本通行和生活权益无法保障。
- 核心资金未落实，却要求依赖未来经营收入开工。
- 内容存在重大史实错误或授权问题。

**调整**

- 机构预约存在但履约不足：减少固定课程空间，调整合作机制。
- 社区使用成立而城市访问较弱：维持片区级公共文化节点。
- 居民投诉集中在特定路线或时段：缩短路线、降低活动强度或取消傍晚活动。
- 单项产品收入不能覆盖增量成本：改为公共采购、提高效率或退出。
- 运营岗位无法持续覆盖：减少开放空间和时段。

**扩展**

- 安全和居民规则稳定。
- 内容、社区复访和机构履约跨周期成立。
- 城市访问具有独立来源。
- 新增建筑的资金、审批和运营能力均已落实。
- 扩展不会挤出基本公共服务或保护维护。

建立项目决策组；锁定红线、建筑编号和资料目录；核对保护名录；启动逐户居民调查；发出结构、消防、测绘和保护评估任务书；明确危险区域。

**第61—90天**

形成分栋工程量和询价包；比较最小开放单元；完成运营责任与数据规则草案；汇总产品测试和居民反馈；召开阶段门评审，决定进入设计、继续补证、缩小范围或暂停。

90天内不承诺全院开工、招商完成、正式夜间开放或投资回报。

## 最终综合判断

十二步分析、夜生活两阶段复核和跨步审校已经完成，用时约51分钟。

项目具有明确的保护与公共文化价值，但目前仍处于“具备策划基础、尚不具备全面建设和招商条件”的阶段。

> **当前定位：居民共生型县政原址公共文化院落。**  
> 首先建设片区级公共文化节点；只有形成可靠档案、稳定预约、跨节点合作和持续运营能力后，才升级为城市文化线路中的专题微目的地。

### 一期最小组合

- 一处通过结构、保护和消防核验的原址展陈空间。
- 一条从正式入口到核心建筑的最短安全路线。
- 原址预约导览。
- 学校、文化机构预约课程。
- 居民及原工作人员口述史共建。
- 社区共享活动。
- 必要的接待、卫生、无障碍、照明和应急设施。

不以填满约2万平方米为目标，不预设全部建筑开放。

### 跨步闭合

政策和场地条件首先要求保护、安全与居民共生，因此项目不能采用商业街区逻辑。

区域供给中已有大量餐饮、购物、影院和住宿，真正缺少的是持续解释县政府原址及大院生活的公共文化场所。因此主题选择“从县政大院到城市共同体”，产品集中于原址展陈、教育和社区共建。

空间上采取“集中开放起步，逐步形成公共脊柱与居民静区”。运营上由业主保留资产、保护和公共任务责任，专业团队执行现场运行，居民参与规则共治，内容及商业伙伴分项接入。

财务上，保护修缮、结构消防和基本公共服务不能依靠未来门票、餐饮或文创收入。每增加一栋建筑，都必须重新通过安全、工程量、资金和运营门。

### 夜间结论

2025年439个夜光格网显示两个相对高值组，但主要对应住宅、政府、停车设施和湘雅医院，不是连续延伸到项目的商业娱乐带。项目中心约处于范围内部第28百分位，华创、万达和富兴附近约为中位水平。

因此只保留：

- 傍晚预约导览。
- 室内低噪声展览或讲座。
- 活动配套茶歇。

酒吧、夜市、深夜餐饮、住宿和大型露天演出继续排除。夜光不能证明人流、消费、营业状态或安全。

### 最大风险

1. 13栋、约2万平方米及8栋保护建筑的口径仍需正式测绘和名录确认。
2. 居民数量存在102户与120户冲突，产权、抵押及实际居住仍未闭合。
3. 墙体、屋面、管线、消防和无障碍问题可能显著改变可开放建筑。
4. 项目材料写“西临黄兴北路”，愿景又称礼堂西侧接近华夏路并设想第二入口，必须由红线和入口测绘解决。
5. 没有项目订单、签到、复访、交易、造价、资金批复或运营合同。

### 最可能推翻方案的反证

- 正式保护或权属文件不允许建议的公共使用。
- 核心建筑无法以合理工程范围达到安全开放要求。
- 居民无法接受访客边界、施工或持续运营规则。
- 原址档案不足以支撑县政史和大院生活主题。
- 社区、学校及文化机构经过真实测试仍不能形成持续使用。
- 基础运营资金没有责任主体，且被要求依赖未经验证的商业收入。

前三项发生时应暂停；第四项发生时降级为社区历史建筑共享场所；后两项发生时维持最小开放，不升级城市微目的地。

### 立即决策事项

- 确认资产、建设和运营责任主体。
- 完成正式红线、分栋测绘、保护名录和入口核验。
- 完成全部受影响住户的产权与使用基线。
- 启动分栋结构、消防、管线和无障碍检查。
- 整理原址档案并建立口述史授权规则。
- 在合法安全场所测试展陈、课程和社区活动。
- 取得最小开放单元的工程量、报价和资金来源。
- 在上述阶段门通过前，不启动全面招商或夜间常态经营。
